# 摔落保护 × 冰霜行者：实现边界

> 本页描述已写入的方案，不是游戏验收结论。提交 `27d72a0` 的 build、compile-check、无 JEI/REI 编译与静态检查成功，JUnit 43/43；尚未启动本轮游戏验收。最终仍须在一次游戏进程内逐项记录结果，含跳过及原因。

## 对象、方向和输入

两个方向的新版都按动作只接受可实际**穿在脚部的靴子**。融合书装载、直接融合、升级及翻转使用同一方向检查，不按两个附魔原版适用对象的交集盲目判断。旧装备上的不适用载体不改数据、不批量迁移，保留旧运行路径并提示；数据包若把该精确方向映射为其他签名，不强行套用本实现。

主动键默认 **G**，切换当前实际装备的主动融合技能默认 **V**，均可在游戏按键设置中重绑。V 显示服务端选中的技能与序号；单技能默认选中，多个技能默认优先第 21 组的耗息疾掘，然后霜波，再霜阶。旧选择失效时回退到仍装备的第一项。客户端只发不含目标、数量和装备的请求；服务端重新验证装备、生命状态、界面和技能条件，并对切换及激活分别限速。断线和关服清理选择。

## 摔落保护 ▷ 冰霜行者：霜势缓冲

穿着实际靴子经历一次可造成伤害的非致命摔落，原版摔落保护仍正常减伤。代码观察该次原版保护计算中靴子上摔落保护对加算保护值的贡献，不重复调用附魔效果；在原版保护值 0–20 封顶后，计算该贡献相对“没有这部分贡献”实际额外减免的伤害，且不超过该次观察到的总魔法防护减伤。被取消、无有效减伤、伤害致死或图腾救回的摔落不积攒。其他附魔已有的防护、抗性与吸收不会被删掉，也不应全部算作本靴的霜势。

霜势在该玩家当前靴子上积攒，副位等级限制在 1–6 后上限为 `min(20, 8 + 2 × 冰霜行者等级)`，每次有效蓄势刷新 400 tick 有效期；换靴、修改该融合、换维、死亡、断线及关服清理。G 释放一次，向当前水平朝向生成短暂向前移动的**虚拟**霜波：每 tick 前进 0.55 格，基础范围和寒冷/缓慢时长随霜势及副位等级增加，遇到实体碰撞方块或未加载区域停止，不生成水或方块。仅作用视线内、原版世界边界/出生点检查允许的合格目标；玩家受 PvP 与队伍规则约束，村民、驯服生物、队友、无敌者及未攻击玩家的中立生物受保护。一个波最多记录 128 个目标，全服最多 128 个波；满额时不消耗霜势。该效果直接施加冻结/缓慢而不是伤害：原版检查不保证第三方领地或状态保护插件也能拦截，必须实测。

边际归因仅接受当前实际执行的所有 `DAMAGE_PROTECTION` 条目直接为 `AddValue`，且观察到的各条增量与最终总值一致；含乘法、设置值、`AllOf` 包装（即便内部都加算）或无法对应的外部修改时，不猜测贡献、不蓄势并给出提示。其他模组在方法内部篡改加算值或以非常规方式处理伤害仍可能逃过检测，不能把此保守策略当成任意模组的严格证明。

## 冰霜行者 ▷ 摔落保护：空中霜阶

穿靴、未飞行且未处于水中时，空中主动使用，在脚下允许的位置放置 2/16 格高的临时干薄冰。霜行等级 I 只放中心一格，II 及以上尝试 3×3；每格单独检查区块已加载、世界边界/出生点、玩家权限、必须是原本无流体的空气且薄冰碰撞范围无活体。没有任何位置成功时不计次数。一次离地最多成功 3 次，间隔 30 tick；踩在本模组薄冰上不重置，落到其他地面或入水才重置，换维、死亡、断线与关服清理。薄冰正常老化或打碎后为空气，不生成水；不替换原有水、植物或其他方块。

原版主位冰霜行者的岩浆等行走伤害免疫保留；会替换原水的原版冻水部分与此设计冲突，予以替代。实现将作用域限定为该靴子、该方向和原版霜行附魔的 `location_changed` 计算，逐次拦截 `ReplaceDisk`/`ReplaceBlock` 对含水格子的写入；同一附魔的数据包额外非写水位置效果、激活/停用逻辑和写到其他材料的效果仍运行，其他未融合的霜行不受影响。自定义效果若直接以别的 API 改写水，不在该拦截范围，须另作兼容测试。第 22 组冰霜行者主位的既有临时水上冰路同样保护原水，原版伤害免疫保留；方向载体与旧路径边界见[第 22 组说明](FROST_WAKE_DIVE_IMPLEMENTATION.md)。

异常融合仍保留旧异常机制：霜势在成功蓄积后、霜阶在成功放置后按原移动/落地冷却执行独立异常效果。这些异常效果可能产生雷电或临时冰，不能误称为普通技能的无世界改动；既有异常规则的保护插件兼容仍未验证。

## 尚待验收

`FrostFallProbe` 已准备载体检查、模拟调用真实摔落伤害管线、取消/图腾、防水作用域和未融合霜行对照，但它不是自然物理落地、真实键盘、波的可见性或多人/领地完整测试，也尚未运行。应在最终单进程中另测：真实行走/跳落与无敌帧、连续落地、保护封顶和其他保护、非加算数据包、波碰墙/敌我/PvP、三次霜阶与冷却/落地重置、权限拒绝、原水与临时冰销毁/老化、换装/跨维/重登、多技能切换、模组监听伤害、原版与自定义位置效果。任何无法覆盖的项目应明确标为跳过并说明原因。
