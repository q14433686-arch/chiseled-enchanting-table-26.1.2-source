# 批量实现索引：附魔动作、归属与例外

本页是把已有设计转为代码时使用的**规则和风险索引**，不是声称以下全部玩法已经实现。完整有序设计仍以 [方向覆盖表](FUSION_MATRIX_COVERAGE.md)、[已选重设计](FUSION_REDESIGN.md) 和各专项实现说明为准；实际代码进度见 [实现状态](FUSION_IMPLEMENTATION_STATUS.md)。相似的有序方向可以共享事件、几何和状态机，但不能因为名字相似而抹平主副方向、目标类别、载体或资源。

开发时可用 `python3 scripts/fusion_batch_index.py --group 42.3`、`--primary smite` 或 `--secondary lure` 找同组有序方向、建议载体和仓库默认签名优先级；`--json` 可供工具处理。此索引不判断是否实装，运行中的数据包可能改变签名，必须再次查询服务器当前解析结果。

## 分派与共同约束

1. **先精确，再副位通配，再已选模板，再其他设计。** 分派以当前已同步的数据包签名为准；数据包新增精确或通配项时不能让本地模板抢先。异常融合、历史旧载体与干净新融合需分开判断。
2. **动作证据不能用粗矩阵代替。** 攻击至少区分真实直接伤害、吸收损失、目标生死、满蓄与刺击；投射物区分谁发射、哪支主弹、命中和移除；采掘区分玩家、方块、位置、真实工具、掉落和经验；穿戴与持握也不能混同。需要手动输入的技能必须由服务器复验。
3. **消耗按真实结算。** 增产不能凭邻近掉落或无源复制；额外破块走真实工具、耐久、原版掉落与权限；装备状态要校验持有人、维度、物品实例、融合内容及存活时间，异常或来源不明应保守退出。
4. **附魔自身语义和原版衔接各算一遍。** 主位原版效果能共存时保留；冲突时以该方向明确的替换/合并为准。跨载体需要按实际数据包重放缺失的原版效果且避免多对重复计算，不能给旧物静默附加新诅咒。
5. **受保护对象与权限。** 自动攻击区分敌对和正在攻击本人的中立生物，保护盟友、驯服者、村民，PvP 需合法；视线和方块交互检查不能冒称兼容所有第三方领地插件。玩家自己手动近击的普通原版行为不由虚拟效果扩大。
6. **可复用观察器不是游戏结果。** `ConfirmedMelee` 在直接玩家攻击和刺击的真实伤害调用前后观察生命与吸收变化，并拒绝无损伤和内部递归；它无法单独证明其他模组在伤害回调内部的每一次变化来源。`VirtualBlade` 是有范围、实体数和遮挡限制的虚拟线段，不能生成可拾取弹药。它也用于 04 的灵刃，回归待验证。

## 43 种原版附魔：抽象触发与特殊注意

表中的“候选证据”只是实现时应选择的观察点，不表示任何方向已经接线或玩家操作已验收。

| `smite` | 命中或击杀亡灵 | 用亡灵类型标签；致命、无伤、图腾、数据包改变均需区别。 |
| `bane_of_arthropods` | 命中节肢、限制其行动 | 用节肢类型标签；非原生载体的原版减速与伤害不可丢失或重复。 |
| `fire_aspect` | 近战点燃、余火 | 原版点火时序与可燃目标；不默认创建火方块。 |
| `knockback` | 真实命中导致的速度/推力 | 无伤刺击、击退抗性、玩家客户端速度同步与瞬移区分。 |
| `breach` | 护甲有效性削减 | 对护甲而非生命上限操作；致密×破甲的双序等效为明确例外。 |

| `wind_burst` | 风爆与起跃 | 主体位移、实际命中、阻挡和落地伤害；不默认更改地形。 |
| `power` | 真实远程弹射物伤害 | 箭归属、原版伤害和拉弦状态，不能复制弹药。 |
| `punch` | 射击的真实击退 | 区分直接命中与后续位移、抵抗和玩家同步。 |
| `flame` | 射击点燃 | 主箭与附加弹体分开；不得擅自放置火方块。 |
| `infinity` | 原版弹药节省和续用 | 仍需真实发射和可用弹药；幻影不得成为可拾取的复制品。 |
| `multishot` | 一次发射的多方向弹体 | 主箭照常；弹丸/烟花、拾取方式和受保护对象分别处理。 |
| `piercing` | 真实路径上依次穿过碰撞对象 | 同一弹体的碰撞批次、墙、受保护对象与重复命中去重。 |
| `quick_charge` | 真实装填与弹仓状态 | 弓拉弦与弩装填不是同一事件；预备/抵扣不能免费制造弹药。 |
| `loyalty` | 返回、归还、所属 | 三叉戟与通用装备方向不同；护主消耗本对忠诚级别且保护其他附魔。 |
| `riptide` | 使用和水/雨中位移 | 合法启动、落点和冲撞；不能用无条件传送代替真实动作。 |
| `channeling` | 合格目标上的引雷 | 天气、天空可见、真实命中与盟友/第三方领地；闪电有附带世界影响。 |
| `impaling` | 水生目标与水相关动作 | 按当前目标规则/数据包判断，不能把所有生物视为水生。 |
| `efficiency` | 真实采掘速度与操作节奏 | 实际工具、硬度、耐久、权限和等级；速度不是免费破块。 |
| `silk_touch` | 保形采集与取样 | 不重复结算或重掷战利品；不同方块、组件及不支持 loot 保守跳过。 |
| `fortune` | 真实采掘增量与运气 | 只认能归因的真实公式差额；后续函数、拆栈、经验和存档原子性需单独处理。 |
| `protection` | 指定装备的实际减伤 | 先辨认真实伤害与护甲归属；爆保主位的单件护甲例外不可泛化。 |
| `fire_protection` | 火焰危险类型的保护与减时 | 核心是防护，不等同于主动点火；区分伤害、火焰状态和装备耐久。 |
| `blast_protection` | 爆炸危险类型的保护与击退 | 不破坏地形；基准、等级、剩余血量和单件护甲排除按选定设计。 |
| `projectile_protection` | 飞行物危险类型的保护 | 原版飞行物、烟花和模组伤害标记不同，不能只按伤害来源猜测。 |
| `thorns` | 装备受击反刺及耐久 | 真受伤与取消/盾格挡/图腾分开；近战替换与投射物原版反伤不同。 |
| `soul_speed` | 灵魂沙土上的实际移动 | 方块类型、真实穿戴、耐久、潜行和振动；不能把一般地面算魂步。 |
| `swift_sneak` | 潜行状态与水平移动 | 护腿实际穿戴、单 tick 位移和碰撞；转头或瞬移不能冒充行走。 |
| `feather_falling` | 实际坠落及减伤 | 未落地、免伤、取消、图腾与真实减轻的量分别计算。 |
| `depth_strider` | 水中行走与移动 | 沉浸、踩地、游泳状态不同；保护原水与正常呼吸。 |
| `frost_walker` | 水面结霜与足下移动 | 原水不得丢失；临时冰破裂不得产水，岩浆变圆石是既定例外。 |
| `respiration` | 氧气、呼吸与溺水 | 气量上限、真实支付、干地/水中和客户端同步。 |
| `aqua_affinity` | 水下真实采掘 | 水下姿态、工具与权限；气泡不能伪造已采方块。 |
| `looting` | 归属玩家的真实击杀与战利品 | 他人伤害、被保护目标、实际 loot 和多模组掉落不能通过邻近扫描猜来源。 |
| `mending` | 真实经验修复与经验入账 | 修补永久上限及消耗次序仅按已选专项；补给保留经验与补给双收益。 |
| `unbreaking` | 真实耐久损耗与免耗 | 免耗事件、最大耐久、装备损毁和取回支付分开；不把模组直接改组件当原版事件。 |
| `luck_of_the_sea` | 钓鱼战利品品质 | 真实抛竿、等待、钓获和数据包 loot；不会制造第二次免费钓获。 |
| `lure` | 咬钩等待与引诱 | 专属优先于副位通配；他人掉落和未证实的敌人不能被当作本次钩获。 |
| `binding_curse` | 穿戴与物品约束 | 穿戴不能脱，持握可切换但不可丢弃/交易/放容器；付费解除与旧物迁移未完成。 |
| `vanishing_curse` | 真死亡时消失及风险 | 图腾救回不是死亡掉落；保留物品和旧物迁移需另行处理，不能提前删除。 |

## 潜行选中模板：42.3

覆盖集恰好是锋利、亡灵杀手、节肢杀手分别与迅捷潜行的**六个有序方向**，不是所有攻击附魔：

- 攻击主位在主手剑、斧、长矛、重锤或三叉戟上：满蓄直接近击造成真实损失后，于目标当前位置留下 120 tick 的固定刀印（每人最多 8 个，超过时先移除最早的）；本人潜行移动经过并有视线后，准备状态持续 100 tick。下一次符合主题且造成真实损失的直接近击消耗准备状态，沿本人视线释放虚拟锋斩。
- 迅捷潜行主位在实际穿戴的护腿上：连续潜行水平移动累计 2 格后准备 100 tick；中途松开潜行清除未准备的进度。下一次符合主题且造成真实损失的直接近击消耗准备状态并释放锋斩。不要求护腿自身成为攻击工具。
- 锋利方向命中合格敌人；亡灵与节肢方向还需分别匹配当前实体标签。直接命中的目标不再吃一次虚拟斩击；虚拟线受墙、未加载区块、实体上限和保护判断约束，不生成物品。伤害 `2 + 0.35×攻击级 + 0.30×潜行级`；距离 `5 + 0.3×(潜行级−1)` 格，两等级均限定 1–10，仅作为当前实现的默认尺度。
- 需要数据包中的精确签名和副位通配都没有覆盖才启用模板。旧的不适用载体保留旧矩阵路径；新装载和翻转、补级通过相同方向载体规则。原版主位能原生附着则原样保留，非原生攻击载体按真实附魔数据重放缺失的伤害及 post-attack，避开 04、10、18 已重放的同一主位。
- 在六个独立的候选验收 fixture 中直接调用真实服务端攻击，但移动、瞄准、时间和环境由探针摆放；墙、取消、目标、工作台和非原生重放的检查不等于自然输入、双客户端 PvP、所有数据包、权属插件或真实手持长矛验证。所有代码、探针及 `VirtualBlade` 对 04 的回归均**尚未运行游戏**。

## 水下选中模板：42.2

同样覆盖锋利、亡灵杀手、节肢杀手与水下呼吸的六个有序方向，沿用 `ConfirmedMelee`、目标主题与非原生主位的去重重放，不与 42.3 混为一项：

- 攻击主位使用实际主手近战武器；玩家眼部在水下、合格目标也在水中时，造成真实损失的直接命中为该目标留下跟随其位置的虚拟气泡，最多存在 100 tick；每人最多保留 8 个，超过时先移除最早的。本人同一物品、同一融合再次对该目标造成真实损失时击破，在水中对半径内最多 16 个其他合格敌人产生水压伤害。目标离水、换维度、融合移除、死亡或超时等情况安全清理；不产生气泡方块或替换水。
- 水下呼吸主位使用实际穿戴的头盔：玩家在水下通过可重绑定技能键主动准备。服务器先核验装备、菜单、水下、空气与空闲状态；支付空气后准备 100 tick。下一次本人水下对符合攻击主题的目标造成真实近击损失时，沿视线向其他水中合格敌人发出虚拟水压斩。准备状态已存在或空气不足时不再扣气；提前离线、死亡、换装或过期不会补偿已支付空气。
- 默认消耗为最大空气的五分之一、最多 40 tick，并保留十分之一、最多 20 tick 的空气；冲击/斩击伤害 `1.5 + 0.35×攻击级 + 0.30×呼吸级`，气泡半径 `2 + 0.2×(呼吸级−1)` 格，等级限制 1–10。数值是当前实现，不是平衡验收结果。
- 真实主位、异常效果、对象保护、旧不适用载体和数据包优先级按上节原则。虚拟伤害不创建武器或弹药，受到遮挡和受害者资格复验；任何第三方实体伤害保护是否被覆盖仍需实际联机验证。
- 六个独立探针在一次性空中区域临时放水并逐格恢复原方块，通过反射刷新原版实体液体状态，再直接调用服务端攻击和技能准备；用于检查费用、取消、目标类别、遮挡和方向载体。它们不等同于自然游泳/输入、空气自然递减、多人或第三方兼容；**尚未运行游戏**。

## 下一批共享事件：约束而非实装声明

- **42.1 连斩护器 / 免耗生锋：六方向。** 同一武器的真实有效命中可复用 `ConfirmedMelee`，但“真实耐久免耗”必须围绕 `ItemStack.processDurabilityChange` 的这一次请求与实际 `unbreaking` 数据包效果前后值取证；现有 `DurabilityReserveSkills` 的观察目前只覆盖自己的 `unbreaking ▷ infinity` 签名，不能把它的结果当作所有物品的免耗。新观察器需要遮蔽嵌套请求、同一持有人/物品及已发生损耗结果验证；非原生耐久效果与第 05 组、第 39.2 组重放去重。准备下一击的加伤需攻击帧预备、有效伤害确认后消费，取消/格挡不花储备。该批尚未实现。
- **40.1 诱标回钩：40 个当前通配方向。** 先判断当前数据包中精确签名是否覆盖，再按近战、真实弹体、真实采掘、防护、移动、氧气、经验、耐久等动作分别接入，不可把一条近战监听器冒称全部通配。已有 `HarvestDropCapture` 的邻近新实体限定仍不能严格证明归属；可继续研究在真实 `Block.dropResources` 的 `Block.getDrops` 返回值与随后产生的实体间按同一玩家、工具、方块、位置和物品对象建立因果链，并对拆栈、后续函数、其他模组重入及未知归属保守跳过。实体来源没有证据之前不能扫描、牵走或复制掉落，也不能把经验当物品。上述更严格的捕获和 40.1 本轮均尚未实现。
- **42.4 护刃 / 承护返锋：六方向。** 攻击主位需要真正的敌方飞行物路径与正面护刃的碰撞，不可拦截本人或盟友弹体、创建可拾取的复制品；保护主位需要按单件装备/盾牌核算真实减伤，不能把受击前后的全部生命变化简单归给每件护甲。多装备、取消、盾格挡、图腾及数据包次序必须在实现前定出可证实的处理方式。该批尚未实现。

这些条目只列事件依赖和风险，用于后续真正批量编码；不得写成已实现、已完成或已验收。
