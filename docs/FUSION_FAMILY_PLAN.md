# 融合玩法：用少量家族机制完成大量组合

> **目的**：让助手完成剩余设计，不要求玩家逐条开会。本方案是可操作的家族设计与逐项映射草案，不是 972 个经过游戏验证的独立技能；已有的用户决定、明确保留和专属方案优先。禁止把简单拼接的文本冒充每一条都经过人工独立创作。

## 一、到底还有多少？是否每项都要独创？

当前清单的 **1,806 个有序候选**中，已有 184 个用户选定专属、124 个已选副位通配、124 个已选模板、402 个助手具体草案。剩余 **972 个有序方向恰好是 486 对正反组合**，不是 972 种互不相关的发明；它们落在本页 **41 种家族组合**里，可通过[双向家族索引](FUSION_FAMILY_INDEX.md)逐对追溯。实际可融合数量仍由游戏输入、装备和数据包决定，不能把理论候选数当成实际可用数。

**建议做法**：少数招牌组合保留专属机制；普通组合使用同一“家族骨架”，但以两侧附魔各自的含义改变触发、目标、形状、操作或代价。每对方向都要有明确的来源行为、结果与适用装备，不能只是换名字/颜色或两条被动相加。正反方向因主位动作和结果组织不同而可感知；用户明确决定的“致密 × 破甲正反同效”仍是例外。

这不意味着缩减或静默取消现有组合：装备适用仍**按有序方向**决定，不能取两种原版附魔的适用交集。融合书、新装载、原位融合、升级与翻转都要检查最终适用范围并说明原因；旧装备不符合新范围时保留原数据和旧效果。单附魔跨界保留原有范围，第三方附魔先通过数据包配置含义与对象才可新装载。上述范围策略仍需实现和回归。

## 二、玩家实际怎么玩

1. **先做本装备本来会做的事**：近战用真实攻击，弓弩正常射击，护甲承受实际伤害，工具合法采掘，靴子真实移动，钓竿真的抛钩收线。主位决定这个契机；取消、盾挡、未命中和死亡结算的具体判断须按技能定义，不能统一假设全部是有效伤害。
2. **副位改变当前动作的用法**：比如把真实箭途变成可回收的护线、把近击变成定向潮刺、把受击的护幕转为刺环；优先让当前装备本身能用。无需为了让剑上的「海之眷顾」生效，先攻击再切钓竿；在非钓竿上把其**等待、择时和好运**转为适合当前动作的互动。
3. **只在需要取舍时操作**：自动发生的形态变化遵从正常动作；需要选方向、保留或释放的技能使用可重绑定的主动键。已选专属的输入/自动触发规则优先。没有目标或未满足条件时给出清楚反馈，不扣没有实际发生的资源；并非每次攻击都强迫按第二个键。
4. **用既有真实事件而非凭空造资源**：经验修补需实际可归属经验或该专属明确允许的耐久奖励；抢夺、时运和海之眷顾的实物收益仅结算合法掉落或已明确写出的奖励。自动追踪、护栏、虚影、轨迹和“势”不等同真实箭、鱼、武器或方块。

### 可辨识的最低标准

- 同一装备的两个不同融合，不只改数值或粒子，至少在**目标、形状、时机、触发或玩家取舍**中体现其含义；不要求所有条目发明全新的按键和实体。
- A▷B 与 B▷A 对照说明**两侧谁的真实动作起手、另一侧怎样改变结果**；不能仅交换名称。已选例外除外。
- 家族规则不能在没有鱼竿时声称钓到鱼、没有经验时声称已修复，也不能因小概率双场景交集把技能做成难以使用的摆设；环境限定清晰显示，并在相关环境提供实际作用。
- **先可用再加复杂度**：保留强力玩法，具体收益与冷却可配置并实测；无需让所有装备每击都同时产生记号、主动技能和新资源。

## 三、43 种附魔各自贡献什么

下表是对未有专属规则的常规方向的语义组件，`主位`决定真实起手，`副位`决定如何改造**同一来源装备的动作或其虚拟产物**。比如副位“火矢”可以把剑的锋形变为沿途燃烧的虚拟矢线，**不需要剑真能发射箭**。需要真实材料、真实经验和真实投掷物的行为仍不得伪造。数据包新增的第三方附魔不能直接猜测这些行为。

| 附魔 | 主位动作与起点 | 作副位时改变什么 |
| :--- | :--- | :--- |
| 锋利 | 近战武器有效命中 | 将主体效果收束为定向单体锋形；玩家指定目标或方向。 |
| 亡灵杀手 | 近战命中合格亡灵 | 将主体形态变为对合格亡灵生效的圣击或圣域；不要求起手目标同时是亡灵。 |
| 节肢杀手 | 近战命中合格节肢生物 | 将主体形态变为束缚或断节；目标限定节肢生物，不生成蛛网。 |
| 火焰附加 | 近战命中并点燃或利用已有余火 | 用接触余火改变主体命中，可留火或选择提前消耗；不放火方块。 |
| 击退 | 有效近击及目标实际位移 | 把主体变为定向近身推击；轨迹只记录真实位移。 |
| 破甲 | 武器有效命中有护甲目标 | 给主体一次针对护甲的开隙或穿甲，不损坏目标装备。 |
| 致密 | 实际落势或重击 | 把主体压成有重量的落击；真实落势强化，不能把虚影冒充真实撞击。 |
| 突进 | 真正蓄力、踏步或突刺 | 让玩家可控地沿选定方向运动；走碰撞，不能瞬移。 |
| 横扫之刃 | 一次真实横扫及有效命中 | 将主体展开为扇形或横弧；同一目标按该次规则结算。 |
| 风爆 | 重击产生真实风压或起跃 | 将主体变为可选择的起跃气流或定向风压。 |
| 力量 | 真实蓄射及命中 | 将主体蓄住并收束为强劲单线；同装备可释放虚拟矢形，不凭空产生真实箭。 |
| 冲击 | 真实弹体造成有效推移 | 让主体沿射线方向产生投射式推击，与近身击退的来源不同。 |
| 火矢 | 发射时带火的真实箭及其路径 | 让主体轨迹留下短暂箭火线，区别于火焰附加的接触余火。 |
| 无限 | 真实弹药按规则发射 | 为主体提供一次不可拾取虚拟续影或节省一次明确的动作成本；不能重放真实掉落/经验。 |
| 多重射击 | 一次真实分射 | 将主体分成数道虚拟侧线或收束成一线；不生成可拾取副弹药。 |
| 穿透 | 真实弹体穿过实体或有效穿透命中 | 让主体沿线穿过合格实体、遇实体方块停止，不越过权限。 |
| 快速装填 | 真实完成装填并射击 | 缩短主体下一次**真实**准备/再使用时间；作业不能因此直接免费完成。 |
| 忠诚 | 本人的真实投出物及其回程 | 为主体增加可见回程；只召回本人同一实体，虚影回扫不能变成新物品。 |
| 激流 | 合法环境中的真实激流运动 | 让主体形成可控的真实冲游或虚拟潮线，不生成水、不瞬移。 |
| 引雷 | 真实合格命中及该方向引雷条件 | 将主体换为定向虚拟电弧；是否合并原版真实雷击按方向决定。 |
| 穿刺 | 合格水生目标上的真实武器命中 | 将主体换为水生目标的定向水刺；不放水、不复制三叉戟。 |
| 效率 | 真实工具完成合法作业 | 让主体的下一次真实准备或合法作业更快，不能无工具破块。 |
| 精准采集 | 真实合法保形采集 | 保留或选择主体的一次完整结果；不复制方块实体、容器或掉落。 |
| 时运 | 合法采集及正常掉落结算 | 在一次允许的真实结算中提供稳定/冒险选择；不是额外复制同一产物。 |
| 保护 | 本装备实际参与减伤或格挡 | 将主体转成可保留或定向展开的护幕；只对后续真实伤害生效。 |
| 火焰保护 | 本装备实际减免火伤 | 将主体换成隔热幕或安全余热；不修改原水、火或岩浆。 |
| 爆炸保护 | 本装备实际减免爆炸伤害 | 将主体换成抵爆或不破地形的反推；不凭空制造真实爆炸。 |
| 弹射物保护 | 本装备实际防住或减免飞行物 | 将主体换成朝向可选的拦截形态，只处理合法敌方真实弹体。 |
| 荆棘 | 本装备实际反刺合格攻击者 | 将主体换为接触反刺或虚拟刺线；没有攻击者时不伪造来源。 |
| 灵魂疾行 | 魂沙/灵魂土上真实移动 | 沿真实移动留下魂迹并允许主动借势；魂土地形的限定必须可见。 |
| 迅捷潜行 | 真实潜行移动 | 让主体进入低姿态行进或伏线；不用依赖侧击、背击。 |
| 摔落保护 | 真实下落、着陆与减伤 | 将主体变为缓冲或可控落势；不伪造落差、不无限飞行。 |
| 深海探索者 | 真实水中游动 | 将主体换成可控的虚拟潮线或水中推进；不替换水。 |
| 冰霜行者 | 安全临时冰路或寒霜动作 | 让主体产生寒意或安全临时冰路；不覆盖原水，冰消失不产水。 |
| 水下呼吸 | 真实水下呼吸或氧气变化 | 将主体化为可触碰补氧的虚拟气泡或可留存的气息；不足不暗扣氧气。 |
| 水下速掘 | 真实水下合法工具作业 | 将主体投入下一次真实水下作业的进度；不能免费破块。 |
| 抢夺 | 本人真实击杀与合法掉落 | 将主体用于本人该次合法战利品的回收或额外奖励结算，不扫描他人。 |
| 经验修补 | 本人真实经验修复本装备 | 将主体连接到真实经验支付或明确设计的耐久修复，不重复记账。 |
| 耐久 | 本装备真实耐久损耗或免耗 | 将主体保留为下一次实际损耗保护；不可损坏物品需另有明确适配。 |
| 海之眷顾 | 本人真实鱼钩、咬钩及收线 | 把主体变为“浮标提示—玩家择时—稳定或冒险”的节奏；非钓竿无需伪造钓鱼。 |
| 饵钓 | 真鱼钩的吸引与等待 | 作为副位使用已选 40.1 通配；有精确专属时专属优先。 |
| 绑定诅咒 | 约束实际穿戴/持有的绑定装备 | 作为副位使用已选 40.2，保留不能丢弃等严重代价和付费解除。 |
| 消失诅咒 | 真正死亡后按规则消失 | 作为副位使用已选 40.3，图腾等救回时不能提前删装备。 |

## 四、41 种家族骨架：两方向的手感

## 五、优先级、适用与工程边界

1. **先已有选择，再一般家族**：用户已选精确效果和明确保留最高；已有副位通配、已选模板和已有具体助手提案按覆盖清单分派。这里不能覆盖 01 组、39.1、25.3、40 组及其他用户决定。旧 1,020 条展开有 48 条已被 53 批替代；剩余 G 行是历史候选，遇到非钓竿必须换竿等问题，应按本页修订，不能照旧表直接实现。
2. 每个方向的最终载体仍由实际能力、用户已选范围和数据包规则独立确定。表内「建议」不是最终白名单；不能因为图省事缩小单附魔跨界。无能力、无授权或不足以定义副位时应清楚报告并保留旧装备，而不是偷偷产生虚假成功。
3. 本装备真实事件产生的状态绑定玩家、装备和有序对；换手、满背包、交易、退出、死亡、重登、换维与区块卸载须有无损策略。一次真实事件、一次弹体、一次掉落及一次修补不得被多个钩子重复结算；融合自己的副作用不可递归触发自己。
4. 额外挖掘走真实玩家、工具、权限、附魔、耐久和掉落逐格处理；横刈额外范围只收成熟作物，中心和草叶原有行为不变。保护原水，安全薄冰消失不生成水；用户明确允许的岩浆永久变圆石以及致密×破甲达标真实挖坑保留。
5. 自动目标、友军、村民、玩家 PvP、第三方领地、真实雷电、可拾取物及经济强化须逐项验证。强力不等于无限递归；用户已选的消耗品经验与补给双收益和诅咒代价不能因统一模板被悄悄改弱或删除。

## 六、哪些值得找玩家讨论

不再询问每个普通方向。只有**会改变世界/物品存续、严重诅咒、稀有资源经济、多人生死或强烈改变操作习惯**且不存在已选规则时，才收敛成少量代表问题；助手先给推荐，不要求玩家设计数值或一千条技能。其余家族先由助手完善，发现不适配再针对该方向修订。第 52、53 批可以作为代表性玩法预览，而不是要求用户逐个投票。

接下来需要完成的是：对每个方向写清最终载体与明确的同装备玩法、逐类检查输入和触发可行性、建立实现前测试清单；已有静态覆盖只保证索引可追溯，不能宣称游戏机制已完成或经过测试。
