# 第 16 组：防爆反击与护值缓爆

> **代码进行中，目标版本编译和游戏均未验证。** 下列数值为助手选择的可调初始值，不是用户逐项确认的平衡值；原始用户决定和范围仍以 `FUSION_REDESIGN.md` 为准。

## 方向与范围

- **爆炸保护 ▷ 保护「蓄爆反击」**：四件护甲实际穿戴时，本件普通 `armor` 属性修饰值不计入爆炸伤害；同时穿戴的其他装备、基准值、状态和本件护甲韧性仍参加原版计算。原版爆炸保护本身保留。爆炸击退抗性不低于每级 15%，与原版已有抗性取较大值，避免简单相加重复计算。
- **保护 ▷ 爆炸保护「护值缓爆」**：保留主位保护的正常防护；真实爆炸伤害中，再合入副位数据包的实际爆炸保护数值，以及本件实际保护贡献的 50%。最后仍由原版统一按其保护上限结算；不会把副位作为完整第二次伤害或把本件护甲白值去掉。
- 两个新方向只接受四种护甲类载体，必须在正确槽实际穿戴才能生效。新融合书装书、直接融合和升级均按此规则拒绝不适用物；旧不适用载体保留原数据和旧效果。该范围选择不影响其他融合或单附魔跨种。

所有基础投影使用已有附魔投影规则。普通原版护甲按原版主附魔及数据包条件计算一次；对实际分类为护甲但原版标签不接受该主附魔的载体，损害计算中额外调用一次数据包的主防护效果，不伪造投影或触发两个副位。反向的副位同名原生附魔若已经独立存在，不重复执行副位。保护主位的百分比只对能从实际原版运行中安全归因的加法贡献计入；非加法数据包效果仍正常运行，但不猜测其折算贡献。

## 反爆的初始公式

- 穿着爆炸主位装备期间，按真实损失的生命与吸收量记录 40 tick（2 秒）滑动窗口；**超过** 10 生命点（5 颗心）触发一次，不要求最后一击本身是爆炸。盾挡为零伤、取消伤害和 `/kill` 不触发；图腾处理后仍活着才可结算。每次自动触发后窗口清空，取消或死亡不制造地形爆炸。
- 默认基础半径为 **3 格**，基础伤害为 **4 生命点**。等级系数 `L=(爆炸保护等级+保护等级)/2`；血量系数 `H=最大生命/max(1,当前生命)`。半径为 `3×L×H`，伤害为 `4×L×H`。初始安全上限分别 64 格、100 生命点和最多 256 个目标；基准、窗口、阈值、抗推、折算和各上限均可调整。封顶以后不再无限线性增长。
- 并排多件时，白值排除所有符合方向的实际装备；反爆窗口只选等级和最高的一件，避免同一受伤事件被四件无限重复。窗口绑定维度、槽位、物品实例和有序对；更换装备、死亡、离线或维度变化清理。发动时仅作用可见且位置允许交互的敌对生物、正攻击玩家的中立生物和合法 PvP 玩家；排除盟友、驯服生物、村民与无仇恨的被动/中立生物。直接调用玩家归属的爆炸伤害，不创建原版地形爆炸或火方块，其他模组的伤害取消事件仍可处理；有重入防护。

## 技术和风险边界

装备的普通护甲在防具可能损坏前快照，按原版属性计算顺序在内存重算、去掉该装备组件中实际生效的 armor 修饰符，不临时修改玩家属性或装备；护甲附魔、其他装备和韧性不删除。若其他模组复用同一个属性修饰符 ID 或在该次伤害回调中重写属性，归属可能无法完全区分。装备切换与原版每 tick 属性同步之间仍需游戏验证。

原版真实爆炸推力及发给玩家的向量使用同一次抗性计算；非原版直接施加速度/其他爆炸实现可能绕过。实际受伤捕获发生在生命/吸收结算，并在伤害/死亡/图腾链完成后判断；第三方在内部同步改变生命、装备、取消伤害或重入时可能影响归因。反爆不请求方块操作，不保证第三方伤害效果或插件自身不改地形。PvP、视线、保护模组及服务端/客户端 Mixin 组合必须实测。

本文件只描述准备中的实现，不能把静态检查、纯计算测试或单客户端 fixture 当作最终游戏验收。
