# 掉落物危险与归属：代码修正边界

> 代码已写，尚未进行本轮游戏验证；不能据此认为单附魔跨种或诅咒全量完成。

- 防火跨种的落地物只针对火焰/岩浆伤害防护，防爆跨种只针对爆炸伤害防护，不再把新掉落实体永久设为对所有来源无敌。绕过无敌的伤害仍按原版处理；不改变岩浆、水或地形。
- 忠诚落地回收只对真实 `ItemEntity` 上可解析且活着的玩家投掷者生效；若原版拾取目标另有指定，则必须与该玩家一致。没有明确归属时，不把它交给附近任何玩家；其余处理沿用原版，可能需要进一步补充安全找回。这个归属条件不声称已覆盖所有模组物品来源、玩家死亡掉落或跨维度情况。
- 对确认归属的物品，背包只插入一部分时，未插入的数量和全部组件保留为原掉落实体；背包满时忠诚救回将余量移到本人位置，并保留该玩家拾取限制。不会因为 `Inventory.add` 报告部分成功就删除整个实体。
- 旧版本可能已经把某些掉落实体的 `Invulnerable` 标记写入存档；因为无法区分它与管理员或其他模组的设置，新代码**不会盲目清除历史标记**。新掉落实体不再由这些路径写入该标记。具体后果和存档迁移需实际测试。
- 内置服务器探针已准备检测火/爆炸/普通伤害、无归属、拾取目标冲突和部分插入余量，尚未运行；两位真实玩家、领地、死亡掉落、卸载/重登与旧标记迁移仍待测。
