# 第 39.6 组：灵魂疾行 × 迅捷潜行

> **目标编译与 62 项 JUnit 通过，尚未游戏验证。** 本文是实现边界，不表示此前所有建议或数值均由用户逐条确认；不能把编译或准备中的探针当成游戏实测。

## 魂步跨域：灵魂疾行 ▷ 迅捷潜行

- 新融合书装书与直接融合均要求靴子；技能只在实际穿戴时运行。靴子保留其可投影的原版灵魂疾行，不强行给靴子添加原版迅捷潜行。
- 在数据包 `minecraft:soul_speed_blocks` 方块上实际疾行时，按真实水平位移逐 tick 积累魂能；空转与超过 1.5 格的单次位移不计。默认最多积 200 tick，自最后一次积累起 400 tick 过期，两项可配置。换靴、换维、死亡和断线清空，不保存到物品或制造实体。
- 在其他实心地面潜行**移动**时，每 tick 消耗一点魂能，把本人的潜行速度提高至至少 `min(1, 0.3+0.15×副位等级)`；已经更快则不降低或再叠加同一收益。期间只压低自身的脚步、落地和游泳**振动监听**，不取消攻击、破坏方块及其他游戏事件；原版潜行本就消音的部分不重复计为额外收益。

## 潜魂穿隙：迅捷潜行 ▷ 灵魂疾行

- 新融合只用于护腿，并须实际穿戴；保留可投影的原版迅捷潜行。于灵魂沙土潜行移动后获得默认 120 tick 的魂形准备期。
- 朝向真正可进入的一格高通道，用可重绑定的主动技能键进入默认 120 tick 爬行；无合法入口、坐骑、飞行、水中或未准备好时不消费准备。再次按键可提前停止；切换装备、换维、死亡或断线清除。玩家仍自行移动，不传送、不无视碰撞；默认爬行速度目标 `min(0.9,0.55+0.05×灵魂疾行等级)`，不降低已更快的原版/其他模组速度。
- 服务端向追踪客户端同步临时爬行标记，双方请求原版 `SWIMMING` 爬行姿态，由原版碰撞盒和站姿适配决定能否进入/起身。取消或到期时若仍在低矮通道，原版会继续使用合适的低姿态，不能把玩家强行嵌进天花板。准备期和持续时间可在游戏内签名配置修改。

## 兼容与待验收

- 旧不适用载体不改数据：正向保留旧版潜行速度和隐身分支；反向以前没有专属签名，仍回退旧矩阵。新签名只在正确载体切换到新技能。已有的独立畸变仍走正常触发及冷却。
- 速度只修改自己的临时属性、与正常更快速度取较高目标，不移除其他来源的修改器；同名未知修改器存在时保守跳过，不抢占。非原版数据包对附魔速度或物理做全局改动时仍需回归。
- 已准备一次性世界中的双向站台载体验证、模拟位移积势、振动筛选、真实姿态盒、走廊与墙碰撞探针；探针在一个服务端 tick 内人工位移，不等于真实键盘移动。联网同步、真实幽匿感测器/尖啸体、图腾、传送、实体碰撞、缩放、其他移动模组及服务器权限均未游戏验证。最终应在完整实现后一次进程内实测并逐项记录。
