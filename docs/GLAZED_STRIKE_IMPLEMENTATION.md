# 火焰附加 ▷ 精准采集：燃烧碎釉

> 本页记录实现和待验收边界，不是游戏验收报告。全部重设计完成后，仍需在同一游戏进程中逐项记录通过、失败、跳过及原因。

## 适用对象和操作

新装载支持**主手剑、斧、长矛、重锤**；直接融合、融合书装载、升级与翻转都按该方向检查载体，不取两个附魔原版适用对象的交集。多角色混合装备只要具有其中任一武器分类即可。旧的不适用载体继续保留原数据和原效果；数据包将该对映射到其他签名时，不强行套用本技能。

火焰附加为主位：在原版支持该附魔的装备上继续使用原版投影和原版后置效果；若装备没有该原版附魔（例如默认规则下的斧），实际非格挡命中时由本技能补上 `4 秒 × 火焰主位等级` 的点火（计算上限 10 级）。已存在原版火焰附加时不再补第二份计时；火焰注册项不存在、目标免火或伤害被取消/格挡时不补点火。这个补足是本方向在非原生载体上的固定规则，**不是重放数据包定义的原版附魔效果**，而且发生在原版后置攻击效果之前；修改附魔规则的模组/数据包仍需兼容测试。副位不额外投影为原版精准采集。

瞄准方向没有侧身或背击限制。普通挥击在 `Player.attack` 开始时记录蓄力和目标是否已燃烧，必须达到现有 `melee_full_charge` 配置阈值。长矛普通刺击按同一蓄力阈值；原版长矛持续动能攻击在已经达到物品自身 `delay_ticks` 且原版判定本次可造成伤害时，视为该攻击方式已蓄势。要先有火：**本次攻击自己首次点燃的冷目标不会同时触发碎釉**；下次满足条件的命中可以触发。

## 结算与边界

同一件主手武器在同一次真实、未取消、未格挡的直接伤害调用中确认后，于服务器 tick 末直接追加一次归属于攻击者的魔法伤害：`3.2 + 0.24 × 目标护甲值 + 0.6 × 火焰等级 + 0.5 × 精准等级`。魔法伤害绕过原版普通护甲，但仍经过其他伤害事件、药水、PvP 等处理；这次追加临时绕开原攻击造成的无敌帧，并恢复原来的较大无敌帧。该 tick 末结算不需要再次按键。普通近战触发冷却沿用配置，未命中、低蓄力、取消或非致死格挡不消耗碎釉冷却。每 tick 待确认和已确认数量分别上限 256。

仅对玩家主动攻击的非盟友、非无敌生物及规则允许的 PvP 对象生效；它不是自动索敌，因此主动攻击未结盟村民等对象仍可能触发。技能不放置火方块或釉陶、不改变地形。对新武器载体，旧版碎釉采掘自动熔炼/釉陶和旧战斗路径不叠加；旧不适用载体仍走旧路径。

真实攻击直接致死时，不对尸体再造成额外伤害，但会在 tick 末显示碎釉特效并记录发现。Fabric 的 `AFTER_DEATH` 不提供盾牌格挡标志，部分格挡后仍致死的情况可能显示碎釉并消耗冷却；非致死部分格挡则不触发。图腾救回、受伤拦截及不同模组的重入顺序仍需游戏验证。
