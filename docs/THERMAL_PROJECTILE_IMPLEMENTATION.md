# 第 14 组：火矢 × 冲击

> `03b3df1` 通过目标编译与 82 项 JUnit，游戏验收尚未进行。具体数值、弓弩适配与结算细节是按已选方向的助手设计，不代表已做实际游戏测试。

## 火矢 ▷ 冲击：热障箭

- 新融合支持**弓和弩**，只给真实中央箭携带会话内热障，不制造或夺取投射物。飞行时显示少量火焰粒子；以真实箭一 tick 的可见路径和附近投射物下一步的相对路径估计接近，默认半径 **1.5 格**，可配 `barrier_radius_tenths`。
- 只拨开有明确敌方归属、正在接近的真实飞行物：敌对生物、正在攻击施术者的中立生物，以及允许 PvP 的非盟友玩家的飞行物。村民、盟友、驯服生物、本人、无明确归属和已插入方块的飞行物不受影响。实际方向加一个侧向速度，保留原来的投射物、归属和正常伤害；每支热障箭最多影响 32 个、每个只处理一次，不复制弹药。
- 两条路径各自以实体方块和世界边界裁剪，预测的最近点之间还要视线畅通；不放火方块、不改液体。搜索范围和预测速度有界，极高速第三方弹体、实体 tick 先后和服务器同步需要游戏验证。
- 保留火矢主位的实际附魔效果。弓上由原版运行；弩如没有原版实体化的火矢，则调用该附魔当前数据包的真实 `projectile_spawned` 效果一次，不硬编码点火、不重复运行已有原版附魔。

## 冲击 ▷ 火矢：落点火涡

- 新融合支持**弓和弩**。真实中央箭必须成功伤害合格目标、原版推力实际改变目标水平速度，才记录该目标；完全抗击退、无伤、受保护对象及末影人特殊传送不记。目标落地或连续 3 次观察近乎停止时，在目标位置形成虚拟火涡；最多等待默认 **80 tick**，过期不生成。
- 默认火涡维持 **60 tick**；半径 `min(5, 1.5 + 0.25 × 冲击等级)`。每 5 tick 尝试作用于范围内合格敌人，同一敌人至多成功受一次 `1 + 0.5 × 火矢等级` 的火伤和短暂燃烧；伤害被原版无敌时间或其他事件取消时不点燃，可待下一次尝试。绕墙伤害被视线检查阻止，不生成任何火方块。
- 冲击主位保留真实数据包的击退效果和原版抗性。弓上由原版运行；弩上在原版其他附魔之后补算一次当前数据包的冲击数值效果，若已有原版冲击则不重复计算。仍使用真实弹药。

## 旧效果与边界

- 旧版“命中爆裂”和“即时点燃落点周围”仅在不适用的新载体旧装备上保留，新有效载体不叠加这两条旧效果。若数据包另行重映射签名，不强行覆盖。两条工作台路径均按实际箭射击能力检查；旧融合数据不被批量删除或迁移。
- 热障箭、着陆记录和火涡均绑定施术者、维度、来源物品对象及融合身份；物品离开背包、死亡、断线、换维、重启、弹体卸载或过期会清理虚拟状态。全服和单箭数量有上限，不读取其他玩家掉落或生成真实物品。
- 服务端 `mayInteract` 和 PvP/队伍检查不能证明第三方领地插件兼容。火伤回调、模组弹体运动、箭碰撞回调、不同实体落地和人工多次推进与真实时序的差异需在本轮单进程验收中核实；多人、服务器专用和外部保护无法覆盖时应如实跳过。
