## 现在到底能测什么

本轮交付的是默认关闭的临时命令入口，不是正式研究页。
可以亲手测试：绑定附魔台 → 效率Ⅰ样本开始 → 低质量解析被拒绝 → 提供效率Ⅱ样本 →
解析得到证据 → 确认研究结论 → 查询制造资格 → 取消/解绑/重进后知识保留。

**不能测的内容：**效率作业试验、临时效率效果、正式新页及美术、制造效率Ⅱ的物品输出与费用、
专精战斗效果、旧等待/磨损迁移。命令原型不证明研究有趣，只先让状态与操作不再停在纸面。

不会免费发书、不会凭空完成实践、不会消费样本，也不会开始锁住旧加工入口。
试验路线明确标为 NOT IMPLEMENTED，没有“直接完成作业”的测试作弊命令。

## 开启（测试包编译通过后）

1. 退出游戏/服务器，安装本轮1.1.0、Minecraft26.3构建；不要使用旧轮artifact。
2. 在该游戏实例的 `config` 文件夹新建一个**空文件**：
   `cet-research-prototype.enabled`（不能变成 `.enabled.txt`）。
   联机时由服务端实例放置此文件；只有客户端放文件不能启用服务器。
3. 重启游戏/服务器，进入新测试世界。建议创造模式并允许作弊以方便搭建，但研究命令本身不要求管理员权限。
4. 备选启动参数：`-Dcet.research.prototype=true`。日常玩家不需要用此方式。
5. 不放文件、不加参数时，原型命令与原型课题不启用。

该标志启动时读取；不是游戏内热开关。删除文件后重启可关闭原型。
这不是最终玩法设置或配置UI。

## 搭建

- 放置本mod的篆刻附魔台，周围留空、上方不要封顶。
- 扫描范围默认水平3格、垂直2格；服务器改过配置时以实际配置为准。
- 附近放一个木书架和一个篆刻书架。
- 创造模式取效率Ⅰ附魔书，放入篆刻书架；暂时不要放效率Ⅱ或更高级效率书。
- 站在附魔台附近，记下**附魔台方块自身**的XYZ坐标，不是玩家脚下坐标。

## 一次完整操作

关闭物品界面，在聊天框执行（将XYZ替换为方块坐标）：

```text
/cet_research bind X Y Z
/cet_research
/cet_research start
/cet_research analyze
```

预期：可以开始研究；但当前只有效率Ⅰ，解析不能获得Ⅱ样本证据，提示缺样本。
`start`目前固定选择已实现的解析路线；不是替你完成研究。

把书架内效率Ⅰ换成效率Ⅱ（也可以另放一本Ⅱ），再次执行：

```text
/cet_research analyze
/cet_research conclude
/cet_research
```

预期：解析返回 `OBSERVED`，接着可确认；确认返回 `COMPLETE`，显示
`learned manufacturing limit = 2`。解析书仍在书架，且数量不变。

这里的2是**研究资格**，不是新书、永久装备效果或已经接入旧生产菜单的许可。
不要把旧生产界面是否原本允许效率Ⅱ，当作新资格是否有效的判断。

## 失败与保存测试（很重要）

- 只有Ⅰ时重复解析：不应刷出进度或结论。
- 没开始就解析：不应自动学习。
- 已有证据重复解析：应为重复事件，不应多给东西。
- 绑定后走远（超过8格中心距离）、换维度或拆台：操作应拒绝，不能远程结算。
- 返回有效附魔台：能继续，不丢已记录状态。
- 完成后执行 `cancel`、`unbind`：完成结论保留。
- 正常保存退出再进：研究结论保留，但临时位置绑定不保存，需要重新 `bind`。
- 禁止建造/旁观者：不能通过原型绕过原版交互限制。

命令：`bind X Y Z`、`start`、`analyze`、`conclude`、`cancel`、`unbind`；
无子命令显示当前状态。提示暂为带 `[Research test]` 前缀的英文诊断，不是最终玩家文案。
`FIND_SAMPLE`=缺解析样本；`ANALYZE_SAMPLE`=可以解析；`CONCLUDE`=可确认；
`LEARNED`=已掌握；`REQUIREMENTS`=工作条件不足。

## 怎么反馈，避免拿技术测试冒充玩法测试

这版请判断：是否能明白缺什么、先做什么、为什么被拒绝、学到了什么、知识是否保存。
不要用命令输入的便利性判断最终研究页；命令会被正式页替换，不是长期操作负担。

下个可玩里程碑必须有：选择作业＋有实际作用的试验能力＋观察反馈＋可使用的研究成果，
然后才适合评价动机和趣味性。不能因为这个命令闭环通过，就宣布效率研究做完。

## 自动验证与人工测试的区别

原生客户端探针会通过真实玩家命令分发器操作，验证关闭菜单后绑定、Ⅰ起步、样本质量拒绝、
越界拒绝、Ⅱ解析、结论与资格、样本不消耗、解绑后保留理解。标志：`RESEARCH PROTOTYPE PASS`。
它仍不等于真人试玩。CI未出现该标志之前，不能宣称该路径已自动验证。
