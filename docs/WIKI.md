## 1. 三步快速上手

1. **摆放附魔台与书架**：以纂刻附魔台为中心，周围 **`7 × 5 × 7`**（水平 `±3` 格、上下 `±2` 格，共 `244` 格）内的**普通书架**与**雕纹书架**都会自动识别，**中间放地毯、火把或隔墙都不会挡住书架**；默认开启防实心埋台空间检查（`require_breathing_room = true`），只需保持台面正上方未封死且近邻 `3×2×3` 内留有至少 `6` 格通透空间即可发挥全额书架效力（支持在 `shelf_gates.json` 中自定义，默认原版附魔台仅禁附书 `vanilla_table_mode = "books"`）。
2. **放入目标与材料**：
   - **上格（目标格）**：放入要附魔/升级/退魔的装备、普通书、附魔书，或要置换的原件（如金苹果、钻石剑、玻璃瓶、褪魔残卷等）。
   - **下格（材料格）**：放入主材料（青金石、绿宝石、紫水晶碎片等，看图标轮播任选一种）。如果需要第二种/第三种辅料，直接放在**背包里**就会自动扣除。
3. **点击左侧列表即可生效**：满足材料与等级要求后点击条目直接生效；铁砧合并装备也已移除原版「过多操作（Too Expensive）」累积惩罚翻倍。

## 2. 全部合成配方一览

### 2.1 纂刻附魔台（2 种合成方式）
- **直接有序合成**：顶排中间 `1× 书`，中排 `钻石 + 雕纹书架 + 钻石`，底排 `3× 哭泣的黑曜石`。
- **原版附魔台升级合成**：顶排 `紫水晶碎片 + 雕纹书架 + 紫水晶碎片`，中排 `紫水晶碎片 + 原版附魔台 + 紫水晶碎片`，底排 `3× 哭泣的黑曜石`。
- **桌布混色染色**：手持任意原版染料右键已放置的纂刻附魔台即可给桌布混色染色；挖下掉落时自动保留颜色。

### 2.2 哭泣的黑曜石 ×8（量产配方）
- **有序合成**：外圈 **`8× 黑曜石`** 围住中心 **`1× 恶魂之泪`** $\longrightarrow$ **`8× 哭泣的黑曜石`**。

### 2.3 秘法凝晶（`chiseled_enchanting_table:arcane_catalyst`）
- **有序合成**：顶排 `紫水晶块 + 钻石块 + 紫水晶块`，中排 `绿宝石块 + 哭泣的黑曜石 + 绿宝石块`，底排 `青金石块 + 金块 + 青金石块`。
- **用途**：通用高阶替代触媒，可在**宝藏顿悟、附魔书单书升级、锁定顿悟、单洗词条、破除诅咒**中单颗替代多材料组合（所有功能均同时保留纯原版材料方案，绝不硬锁）。

### 2.4 退魔砂 ×4（`chiseled_enchanting_table:cleansing_grit`）
- **无序合成**：`1× 燧石 + 1× 下界石英 + 1× 发光墨囊 + 1× 骨粉` $\longrightarrow$ **`4× 退魔砂`**（用于单洗 1 条附魔或破除诅咒）。

### 2.5 纂刻秘典（`chiseled_enchanting_table:arcane_grimoire` · 游戏内交互图解指南）
- **无序合成配方一（书架拓印）**：`1× 书与笔（minecraft:writable_book）` + `1× 雕纹书架（minecraft:chiseled_bookshelf）` $\longrightarrow$ `1× 纂刻秘典`。
- **无序合成配方二（残卷重装）**：`1× 褪魔残卷（chiseled_enchanting_table:depleted_tome）` + `1× 墨囊（minecraft:ink_sac）` $\longrightarrow$ `1× 纂刻秘典`。
- **收纳与联动**：可直接放进雕纹书架收纳；也可在**纂刻附魔台界面右上角按钮**无损打开或返回（不会掉落槽内物品），书内所有物品槽均支持左/右键或按键绑定（默认 `R / U`，可在原版「选项 → 控制 → 按键绑定」中自定义）直接调用 JEI / REI 查配方与用途；在附魔台界面内直接对任意槽位或材料图标查完 JEI / REI 按 `ESC` / 退回键返回时，槽内物品图标与左侧附魔列表均无损保留，无需重新打开方块。

### 3.1 普通书架（标签 `#chiseled_enchanting_table:regular_bookshelves`，数量 $W$）
- **三种附魔/升级分工**：
  1. **给未附魔物品直接附魔**：常规附魔（`#minecraft:in_enchanting_table`，不含诅咒与宝藏）`0` 书架即可直接附 **`I` 级**；单靠普通书架给未附魔装备或普通书附魔时，最高直接附到**等级上限的一半** $\lceil M / 2 \rceil$（例如最高 `5` 级最多直附到 `3` 级，最高 `4` 级最多直附到 `2` 级）。
  2. **给已有附魔升级到满级（`0 ~ 38` 个普通书架，`MAX = 2` 为 `22` 架）**：只要装备或附魔书上已经有该附魔 `I` 级及以上，周围普通书架就能逐级解锁直到 **`38` 个普通书架升到满级 `MAX`**（最高 `2` 级的魔咒由 `shelf_gates.json` 中的 `two_level_max_bookshelves = 22` 单独平滑到 **`22` 架**，避免 `I → II` 一步跳满 `38` 架）：
     $$W_{\text{req}}(L, M) = \begin{cases} 0, & M \le 1 \text{ 或 } L \le 1 \\ 22, & M = 2 \text{ 且 } L \ge 2 \\ 38, & M \ge 3 \text{ 且 } L \ge M \\ \operatorname{round}\!\left(38 \cdot \left(\dfrac{L - 1}{M - 1}\right)^{1.25}\right), & 1 < L < M \end{cases}$$
     - **最高 `2` 级附魔**（击退、火焰附加、冲击、冰霜行者等）：`I(0)` → **`II(22)`**
     - **最高 `3` 级附魔**（耐久、时运、抢夺、忠诚、激流等）：`I(0)` → **`II(16)`** → **`III(38)`**
     - **最高 `4` 级附魔**（保护、摔落缓冲、穿透、破甲等）：`I(0)` → **`II(10)`** → **`III(23)`** → **`IV(38)`**
     - **最高 `5` 级附魔**（锋利、亡灵杀手、效率、力量、穿刺、致密等）：`I(0)` → **`II(7)`** → **`III(16)`** → **`IV(27)`** → **`V(38)`**
     - **高上限模组附魔兼容（$M = 1 \sim 255$）**：按上述幂律曲线平滑映射到 `0..38` 档位，直至 **`38` 个普通书架解锁满级**。
- **普通书架平滑经验减免（满 `3` 个起效、每约 `3` 架递增 `1%`、`45` 个满额 `-15%`）**：
  $$\Delta_{\text{普通}}(W) = \begin{cases} 0\%, & W < 3 \\ \operatorname{round}\!\left(1\% + 14\% \cdot \operatorname{clamp}\!\left(\dfrac{W - 3}{45 - 3},\; 0,\; 1\right)\right), & W \ge 3 \end{cases}$$
- **开启宝藏顿悟 & 1 秒实时同步**：普通书架满 **`32` 个**自动开启右上角「宝藏顿悟」；打开界面时拆放书架或存取藏书会在 **1 秒内实时刷新**。

### 3.2 雕纹书架藏书（母本耐久循环 + 「无限」不朽免耗损 + 38 / 42 两档温养回复 + 最高 `-40%` 经验减免）
- **雕纹母本解锁与耐久循环（`tome_consumption_mode` 可配置，生存/创造模式行为一致）**：把附魔书放进范围内的雕纹书架作为母本，未附魔装备也能直接附到该书等级（包括经验修补、精准采集等宝藏附魔），且变为每次只扣 `1~3` 级的绿色量产模式。默认 `tome_consumption_mode = "wear"`（每级耐久 `max_tome_uses = 4`，附魔装备消耗 `1` 点、抄写到书消耗 `book_copy_wear_cost = 2` 点；两项均以数据包 `library_resonance.json` 为准，游戏内文本会读取实时配置显示，不写死份数；耗尽自动退 `1` 级，`I` 级母本耗尽化为雕纹书架内的**褪魔残卷**；也可切换为 `"keep"` 永久保留模式或 `"consume"` 一次性模式）。
- **免磨损标签（`#chiseled_enchanting_table:wear_immune`，默认含 `minecraft:infinity`）获取限定、词条数衰减曲线、抄本代数上限与全馆超载串扰（$\le 25\%$）**：
  - **获取途径严格限定**：移出默认直附列表、移出「宝藏顿悟」池并可选拦截村民交易刷新，**仅能通过「世界探索战利品 / 藏书」、「原版附魔台随机附魔」或「雕纹书架中已拥有免磨损母本时复制 / 铭刻」获得**；
  - **连续免磨损曲线与代数上限扣减（均可由 `library_resonance.json` 驱动）**：当抄本代数 $\text{Gen} \le 2$（`wear_immune_max_generation = 2`）时，母本最大充能上限保持满额 **`4 / 4`**（不提前扣减上限），单本非诅咒词条数 $N \le 4$ 享受 **`100%` 免磨损**，超出 $4$ 条后每多 $1$ 条免磨损率下降 **`6%`**（`wear_immune_overload_decay_per_enchant = 0.06`），保底不低于 `unbreaking_waiver_max_chance`（默认 **`30%`**）；**自第 `3` 代抄本（$\text{Gen} \ge 3$）起失去免磨损特权并开始按 $\max(0,\; \text{Gen} - 2)$ 扣减耐久上限**（`Gen 3 = 3/4`、`Gen 4 = 2/4`、`Gen 5+ = 1/4`），回归常规耐久与「耐久」魔咒免耗损机制；
  - **全馆总承载 $\Sigma L$ 超载「抄错」干扰（封顶 `25%`）**：按范围内**所有生效免磨损母本**的承载度之和 $\Sigma L$ 计算（堵死拆分成多本高承载无限书绕过惩罚的漏洞）：当 $\Sigma L \ge 3.0$ 时，拓印存在概率发生「抄错」（`70%` 降 1 级 / `25%` 串行为无关低阶附魔 / `5%` 串行为诅咒，串行退还 `50%` 经验与材料，概率**严格封顶不超过 `25%`**）。
- **基于附近「广义书架总数 $S_{\text{广义}}$」的平滑分段线性自动温养回复机制**（$1\text{ 游戏日} = 24{,}000\text{ ticks} = 1{,}200\text{ 秒}$，广义书架为普通书架 + 至少放有 1 本书/残卷的雕纹书架，空雕纹不计入，全程连续无跳变）：
  - **基础线性区间（$0 \le S_{\text{广义}} \le 38$）**：从 $0$ 广义书架的 **`6.0 个游戏日 / +1 耐久`（`7,200 秒`）** 随书架数**平滑线性插值**加速至 **`38` 架的 `3.0 个游戏日 / +1 耐久`（`3,600 秒 = 72,000 ticks`）**；
  - **大书库线性冲刺区间（$38 < S_{\text{广义}} \le 42$）**：在 `38 ~ 42` 架之间从 **`3,600 秒`** 平滑线性加速至 **`42` 架的 `1.0 个游戏日 / +1 耐久`（`1,200 秒 = 24,000 ticks`）**；
  - **超满阶渐近区间（$S_{\text{广义}} > 42$）**：超出 $42$ 架后继续双曲平滑加速（保底 `0.5 个游戏日 = 600 秒 / +1`）。

### 4.1 通俗拆解：「原为 XX 级」是怎么算的？等级门槛到底有什么用？
1. **「原为 XX 级」的算法（打折前的原始要求等级）**：
   - **首次直附 / 母本拓印**：同时比较 **① 原版 30 级台比例标尺 $\operatorname{round}(8 + 22 \cdot L/M)$**（如 `锋利 I` 约 `12` 级、**任意满级词条至少 `30` 级**）与 **② 词条自身稀有度基础定价**，取较高值作为「原为 XX 级」；
   - **补差价升级（如 `III → IV`）**：自动按 **`85%`** 折抵已有旧等级进度（$L/M - 0.85 \cdot L_{\text{旧}}/M$），绝不重复收费；
   - **书架打折换算**：叠加最高 **`-40%`** 书库减免后，$\text{当前要求门槛} = \operatorname{round}(\text{原为等级} \times (1 - \Delta_{\text{总}}))$（例如满级词条「原为 `30` 级」叠满 `-40%` 后降为 **`Lv.18`**）。
2. **等级门槛的两大实际用途**：
   - **在绿球模式（有母本拓印 / 物品置换 / 单洗）里 =「入场门票 + 防刷经验锁」**：达到 `Lv.18` 即可点击，但**实际只扣 `1 / 2 / 3` 个整级并保留经验条进度**；同时从数学底层杜绝「花 `Lv.0→3`（仅 `27 点` 经验）附满级装备、转身免费退魔返上百点经验球」的永动机漏洞；
   - **在紫瓶模式（暂无母本硬附 / 顿悟 / 单研）里 =「实际扣除等级」**：没有母本分担时按减免后等级实扣经验点——因此**优先把常用词条做成母本放进雕纹书架**，就能永久解锁 `1~3` 级低耗量产！（游戏内《纂刻秘典》现已升级为**多页章节排版**，在第 `02 / 03 / 04 / 05 / 06` 章配有图文并茂的通俗指南。）

## 9. 功能页解锁、「纂刻的书」与母本锁定

雕纹附魔台顶部新增第三页签 **「纂刻的书」**；它与 **「去除附魔」** 页起初都处于锁定状态，悬停会提示：**未解锁该功能页，请前往纂刻秘典查看详情**。两项解锁均为**按玩家永久生效**，并直接以进度（advancement）为事实源：

| 功能页 | 解锁条件 | 奖励 |
| :--- | :--- | :--- |
| **去除附魔** | 将褪魔残卷放入范围内雕纹书架，点击页签旁的琥珀色献祭按钮，累计献祭 **12 本褪魔残卷** | 解锁本页并获得进度 **「残卷之祭」** |
| **纂刻的书** | 范围内至少 **4 个雕纹书架**各存有至少 **1 本附魔书**（与母本充能相同的充能扫描口径） | 解锁本页并获得进度 **「还要多久……」** |

- **充能总览**：「纂刻的书」会列出范围内雕纹书架上的每一本附魔书，显示剩余耐久 / 有效上限、副本世代、恢复 **+1** 的预计时间、恢复满耐久的预计时间，以及当前恢复档位、当前恢复速率和距离下一阶段还差多少个书架。
- **三种锁定**：选中一本后可免费选择 **锁至 +1**、**锁至满耐久** 或 **永久锁定**；还可一键把所有正在充能的书锁至满耐久。锁定归属于操作玩家 UUID，服务端会封堵手动取出、漏斗/自动化转移、破坏书架、附魔选项生成、仪式消耗、物品置换、铁砧与砂轮等路径；若雕纹书架因爆炸、活塞等外力破碎掉落书籍，或残存旧锁标记的书籍被放入主界面槽位，系统会自动清除锁标记防止产生物品死锁；此外高词条（`≥3` 条）或免磨损附魔书点击 **「全部洗去」** 时需 **5 秒内二次点击确认**（按住 `Shift` 点击可直接执行）。
- **锁定不停止充能**：限时锁到期会自动解除；主人在线时会收到动作栏与音效提醒，书架上的锁定书还会出现粒子标记。提前手动解锁固定消耗 **1 级经验 + 1 个退魔砂**（逐本扣除）。
- 《纂刻秘典》新增第 **09 章「功能页解锁、纂刻的书与锁定」**，完整说明两个页面的解锁方法与锁定规则。

- **数据包优先原则与服务器 / 整合包防篡改锁定机制（`pack_policy.json`）**：
  - **默认严格「数据包优先于游戏内配置」（`override_datapacks = false`）**：任何外部数据包（存档 `datapacks/`、KubeJS、Paxi、OpenLoader 或附属核心模组 JAR）中显式声明的配置项，默认**无条件优先于玩家的 `config/chiseled_enchanting_table.json` 与游戏内面板修改**；被数据包接管的条目会在面板中自动锁定并注明 `📦 当前由外部数据包优先接管生效`，未被数据包涉及的其他选项仍允许玩家自由微调；
  - **多人服务器防作弊保护**：所有附魔花费、书架判定、母本损耗/回复、宝藏顿悟、退魔返还与战利品全部 **100% 服务端权威计算**；普通玩家无 `GAMEMASTERS` / `chiseled_enchanting_table:config/manage` 权限时，本地修改 `config/*.json` 或伪造发包均完全无效，服务端会直接拦截并重推权威规则；
  - **整合包单人防私改策略（`data/chiseled_enchanting_table/chiseled_enchanting_table/pack_policy.json`）**：整合包作者可在 KubeJS（`ServerEvents.highPriorityData`）、Paxi 或自定义核心模组 `.jar` 中覆盖 `pack_policy.json`：
    - `"enforce_datapack_priority": true`：强制锁死数据包最高优先级，即便玩家手动用记事本把 `config/chiseled_enchanting_table.json` 中的 `"override_datapacks"` 改为 `true` 也无法覆盖数据包；
    - `"lock_in_game_config": true`（或按需指定 `"locked_keys": [...]`）：将全部（或指定核心平衡项）彻底锁定为 `🔒 整合包 / 服务器统一配置已锁定（只读检视）`，单人存档面板与 `config/*.json` 外部改档均不再覆写整合包设定。
