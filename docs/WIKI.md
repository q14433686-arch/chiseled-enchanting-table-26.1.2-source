## 1. 三步快速上手

1. **摆放附魔台与书架**：以纂刻附魔台为中心，周围 **`7 × 5 × 7`**（水平 `±3` 格、上下 `±2` 格，共 `244` 格）内的**普通书架**与**雕纹书架**都会自动识别，**中间放地毯、火把或隔墙都不会挡住书架**；默认开启防实心埋台空间检查（`require_breathing_room = true`），只需保持台面正上方未封死且近邻 `3×2×3` 内留有至少 `6` 格通透空间即可发挥全额书架效力（支持在 `shelf_gates.json` 中自定义，默认原版附魔台仅禁附书 `vanilla_table_mode = "books"`）。
2. **放入目标与材料**：
   - **上格（目标格）**：放入要附魔/升级/退魔的装备、普通书、附魔书，或要置换的原件（如金苹果、钻石剑、玻璃瓶、褪魔残卷等）。
   - **下格（材料格）**：放入主材料（青金石、绿宝石、紫水晶碎片等，看图标轮播任选一种）。如果需要第二种/第三种辅料，直接放在**背包里**就会自动扣除。
3. **点击左侧列表即可生效**：满足材料与等级要求后点击条目直接生效；铁砧合并装备也已移除原版「过多操作（Too Expensive）」累积惩罚翻倍。

## 2. 全部合成配方一览

### 2.1 纂刻附魔台（2 种合成方式）
- **直接有序合成**：顶排中间 `1× 书`，中排 `钻石 + 雕纹书架 + 钻石`，底排 `3× 哭泣的黑曜石`。
- **原版附魔台升级合成**：顶排 `紫水晶碎片 + 雕纹书架 + 紫水晶碎片`，中排 `紫水晶碎片 + 原版附魔台 + 紫水晶碎片`，底排 `3× 哭泣的黑曜石`。
- **桌布混色染色**：手持任意原版染料右键已放置的纂刻附魔台即可给桌布混色染色；挖下掉落时自动保留颜色。

### 2.2 哭泣的黑曜石 ×8（量产配方）
- **有序合成**：外圈 **`8× 黑曜石`** 围住中心 **`1× 恶魂之泪`** $\longrightarrow$ **`8× 哭泣的黑曜石`**。

### 2.3 秘法凝晶（`chiseled_enchanting_table:arcane_catalyst`）
- **有序合成**：顶排 `紫水晶块 + 钻石块 + 紫水晶块`，中排 `绿宝石块 + 哭泣的黑曜石 + 绿宝石块`，底排 `青金石块 + 金块 + 青金石块`。
- **用途**：通用高阶替代触媒，可在**宝藏顿悟、附魔书单书升级、锁定顿悟、单洗词条、破除诅咒**中单颗替代多材料组合（所有功能均同时保留纯原版材料方案，绝不硬锁）。

### 2.4 退魔砂 ×4（`chiseled_enchanting_table:cleansing_grit`）
- **无序合成**：`1× 燧石 + 1× 下界石英 + 1× 发光墨囊 + 1× 骨粉` $\longrightarrow$ **`4× 退魔砂`**（用于单洗 1 条附魔或破除诅咒）。

### 2.5 纂刻秘典（`chiseled_enchanting_table:arcane_grimoire` · 游戏内交互图解指南）
- **无序合成配方一（书架拓印）**：`1× 书与笔（minecraft:writable_book）` + `1× 雕纹书架（minecraft:chiseled_bookshelf）` $\longrightarrow$ `1× 纂刻秘典`。
- **无序合成配方二（残卷重装）**：`1× 褪魔残卷（chiseled_enchanting_table:depleted_tome）` + `1× 墨囊（minecraft:ink_sac）` $\longrightarrow$ `1× 纂刻秘典`。
- **收纳与联动**：可直接放进雕纹书架收纳；也可在**纂刻附魔台界面右上角按钮**无损打开或返回（不会掉落槽内物品），书内所有物品槽均支持左/右键或 `R / U` 直接调用 JEI / REI 查配方与用途。

### 3.1 普通书架（标签 `#chiseled_enchanting_table:regular_bookshelves`，数量 $W$）
- **三种附魔/升级分工**：
  1. **给未附魔物品直接附魔**：常规附魔（`#minecraft:in_enchanting_table`，不含诅咒与宝藏）`0` 书架即可直接附 **`I` 级**；单靠普通书架给未附魔装备或普通书附魔时，最高直接附到**等级上限的一半** $\lceil M / 2 \rceil$（例如最高 `5` 级最多直附到 `3` 级，最高 `4` 级最多直附到 `2` 级）。
  2. **给已有附魔升级到满级（`0 ~ 38` 个普通书架）**：只要装备或附魔书上已经有该附魔 `I` 级及以上，周围普通书架就能逐级解锁直到 **`38` 个普通书架升到满级 `MAX`**：
     $$W_{\text{req}}(L, M) = \begin{cases} 0, & M \le 1 \text{ 或 } L \le 1 \\ 38, & L \ge M \\ \operatorname{round}\!\left(38 \cdot \left(\dfrac{L - 1}{M - 1}\right)^{1.25}\right), & 1 < L < M \end{cases}$$
     - **最高 `2` 级附魔**（击退、火焰附加、冲击等）：`I(0)` → **`II(38)`**
     - **最高 `3` 级附魔**（耐久、时运、抢夺、忠诚、激流等）：`I(0)` → **`II(16)`** → **`III(38)`**
     - **最高 `4` 级附魔**（保护、摔落缓冲、穿透、破甲等）：`I(0)` → **`II(10)`** → **`III(23)`** → **`IV(38)`**
     - **最高 `5` 级附魔**（锋利、亡灵杀手、效率、力量、穿刺、致密等）：`I(0)` → **`II(7)`** → **`III(16)`** → **`IV(27)`** → **`V(38)`**
     - **高上限模组附魔兼容（$M = 1 \sim 255$）**：按上述幂律曲线平滑映射到 `0..38` 档位，直至 **`38` 个普通书架解锁满级**。
- **普通书架经验减免（满 `12` 个起效、`38` 个满额 `-15%`）**：
  $$\Delta_{\text{普通}}(W) = \begin{cases} 0\%, & W < 12 \\ \operatorname{round}\!\left(1\% + 14\% \cdot \operatorname{clamp}\!\left(\dfrac{W - 12}{38 - 12},\; 0,\; 1\right)\right), & W \ge 12 \end{cases}$$
- **开启宝藏顿悟 & 1 秒实时同步**：普通书架满 **`32` 个**自动开启右上角「宝藏顿悟」；打开界面时拆放书架或存取藏书会在 **1 秒内实时刷新**。

### 3.2 雕纹书架藏书（母本耐久循环 + 「无限」不朽免耗损 + 38 / 42 两档温养回复 + 最高 `-40%` 经验减免）
- **雕纹母本解锁与耐久循环（`tome_consumption_mode` 可配置，生存/创造模式行为一致）**：把附魔书放进范围内的雕纹书架作为母本，未附魔装备也能直接附到该书等级（包括经验修补、精准采集等宝藏附魔），且变为每次只扣 `1~3` 级的绿色量产模式。默认 `tome_consumption_mode = "wear"`（每级耐久 `max_tome_uses = 16`，附魔装备消耗 `1` 点、抄写到书消耗 `book_copy_wear_cost = 4` 点；耗尽自动退 `1` 级，`I` 级母本耗尽化为雕纹书架内的**褪魔残卷**；也可切换为 `"keep"` 永久保留模式或 `"consume"` 一次性模式）。
- **「无限」（`minecraft:infinity`）获取限定、不朽免耗损与超载串扰（「抄错」$\le 20\%$）**：
  - **获取途径严格限定**：移出默认直附列表、移出「宝藏顿悟」池并拦截村民交易刷新，**仅能通过「世界探索战利品 / 藏书」、「原版附魔台随机附魔」或「雕纹书架中已拥有『无限』母本时复制 / 铭刻」获得**；
  - **不朽免耗损**：附带「无限」的母本在拓印时消耗 `0` 点耐久（支持「经验修补 + 无限」共存）；
  - **超载「抄错」干扰**：若检测范围内的雕纹书架中存在**同时拥有「无限」且其他附魔词条数 $> 3$（即单册总词条 $\ge 5$）**的超载母本，则单本词条数与范围内**广义书架总数 $S_{\text{广义}}$** 越多，附魔时越容易发生**「抄错」**（铭刻为当前所选附魔的更低等级，概率分级递增且**严格封顶不超过 $20\%$**）。
- **基于附近「广义书架总数 $S_{\text{广义}}$」的两档（`38` 架 `10` 游戏日 / `42` 架 `3` 游戏日）自动温养回复机制**（$1\text{ 游戏日} = 24{,}000\text{ ticks} = 1{,}200\text{ 秒}$，其中广义书架包含普通书架、空雕纹书架及含褪魔残卷在内的有书雕纹书架）：
  - **基础区间（$0 \le S_{\text{广义}} < 38$）**：从 $0$ 广义书架的 **`20.0 个游戏日 / +1 耐久`（`24,000 秒`）** 平滑提速至 $37$ 广义书架的 **`15.2 个游戏日 / +1 耐久`**；
  - **第一档突破（$38 \le S_{\text{广义}} < 42$，默认 `38` 架）**：满 **`38` 个广义书架**突破至 **`10.0 个游戏日 / +1 耐久`（`12,000 秒 = 240,000 ticks`）**；
  - **第二档大书库突破（$S_{\text{广义}} \ge 42$，默认 `42` 架）**：满 **`42` 个广义书架**大幅突破至 **`3.0 个游戏日 / +1 耐久`（`3,600 秒 = 72,000 ticks`）**，超出 $42$ 架后继续平滑加速（保底 `1.5 个游戏日 / +1`）。
- **宝藏顿悟稀有度 × 普适度加权抽取**：顿悟池各宝藏附魔按自身稀有度权重与适用装备广度反比动态加权——越普适的核心宝藏（如「经验修补」）顿悟权重越低、越珍稀，专精单类武器的宝藏出现更均衡。
- **箱子式物品持久化、深层铭刻等待与双跳过博弈机制**：
  - **附魔台物品持久化**：纂刻附魔台的两个槽位现已像箱子一样完整持久化保存在方块实体中（关界面、重进存档不掉落，破坏方块时完整掉落）；
  - **深层铭刻等待与有界排队**：**当且仅当**附近**广义书架总数 $S_{\text{广义}} \ge$ 三档中间值（默认 `32` 架）** **或** 范围内雕纹书架母本总附魔词条数 **$\ge 10$** 时触发铭刻等待；单次时长按广义书架密度、母本词条总量、附魔相对等级 $L/M$ 与普适度平滑饱和计算，**单个附魔严格不超过 `5 分钟`（`6,000 ticks`），连续追加时按队列累加，但每台最多 256 步 / 32,000 字符；容量、归属和退款预算在付费前检查**；
  - **双按钮跳过机制（仅当范围内存在至少一册母本时允许跳过）**：
    1. **⚡ 献祭经验跳过**：根据实时剩余等待时间直接扣除整级经验（紫瓶，**最高不超过 `15` 级**），**`0%` 损伤母本**，瞬间完成全部队列附魔（解锁成就 **「燃魂催墨」**）；
    2. **🎲 强行跳过（不献祭经验）**：不扣额外经验，按实时剩余时间计算将一册母本退化为 **「褪魔残卷」** 的概率——**常规封顶 `50%`，使用含「无限」属性的母本附魔时封顶拔升至 `70%`**；一旦触发退化，**优先牺牲相对低等级、低附魔数、低稀有度的母本**，并解锁专属成就 **「心急吃不了热豆腐」**！
  - **仪式归属与取消**：只有发起者可追加或赶工；活动期间锁定目标输入。打开对应附魔台时可用 `/cet cancel-ritual` 取消并保留输入，已支付费用和母本磨损不退。缺失附魔 ID 或目标不符会隔离保留订单，不能通过赶工反复扣费。
  - **共享温养**：同一书架被多台覆盖时只取最快合法速率；仅连续加载观察累计，不补算背包或其他世界的时间。配置改动/换书/卸载会保守重建驻留。
- **两段经验减免叠加公式（总上限 `-40%`）**：
  - 按每种已存非诅咒附魔的相对等级 $r(e) = \min(1, L_e / M_e)$（同名附魔不重复刷分）计算藏书精通和 $E_{\text{总}} = \sum r(e)^{1.25}$：
  1. **公共减免（上限 `-35%`）**：普通书架最高 `-15%` + 雕纹总藏书最高 `-20%`：
     $$\Delta_{\text{全局藏书}} = \min\!\bigl(20\%,\; \lfloor 1.25 \cdot E_{\text{总}} \rfloor\%\bigr), \qquad \Delta_{\text{公共}} = \min\!\bigl(35\%,\; \Delta_{\text{普通}}(W) + \Delta_{\text{全局藏书}}\bigr)$$
  2. **同种藏书额外减免（上限 `-15%`，合计封顶 `-40%`）**：雕纹书架里存有同种附魔书时额外减免：
     $$\Delta_{\text{同种}}(e) = \operatorname{round}\!\bigl(15\% \cdot r(e)\bigr), \qquad \Delta_{\text{总}}(e) = \min\!\bigl(40\%,\; \Delta_{\text{公共}} + \Delta_{\text{同种}}(e)\bigr)$$

### 4.1 通俗拆解：「原为 XX 级」是怎么算的？等级门槛到底有什么用？
1. **「原为 XX 级」的算法（打折前的原始要求等级）**：
   - **首次直附 / 母本拓印**：同时比较 **① 原版 30 级台比例标尺 $\operatorname{round}(8 + 22 \cdot L/M)$**（如 `锋利 I` 约 `12` 级、**任意满级词条至少 `30` 级**）与 **② 词条自身稀有度基础定价**，取较高值作为「原为 XX 级」；
   - **补差价升级（如 `III → IV`）**：自动按 **`85%`** 折抵已有旧等级进度（$L/M - 0.85 \cdot L_{\text{旧}}/M$），绝不重复收费；
   - **书架打折换算**：叠加最高 **`-40%`** 书库减免后，$\text{当前要求门槛} = \operatorname{round}(\text{原为等级} \times (1 - \Delta_{\text{总}}))$（例如满级词条「原为 `30` 级」叠满 `-40%` 后降为 **`Lv.18`**）。
2. **等级门槛的两大实际用途**：
   - **在绿球模式（有母本拓印 / 物品置换 / 单洗）里 =「入场门票 + 防刷经验锁」**：达到 `Lv.18` 即可点击，但**实际只扣 `1 / 2 / 3` 个整级并保留经验条进度**；同时从数学底层杜绝「花 `Lv.0→3`（仅 `27 点` 经验）附满级装备、转身免费退魔返上百点经验球」的永动机漏洞；
   - **在紫瓶模式（暂无母本硬附 / 顿悟 / 单研）里 =「实际扣除等级」**：没有母本分担时按减免后等级实扣经验点——因此**优先把常用词条做成母本放进雕纹书架**，就能永久解锁 `1~3` 级低耗量产！（游戏内《纂刻秘典》现已升级为**多页章节排版**，在第 `02 / 03 / 04 / 05 / 06` 章配有图文并茂的通俗指南。）

## 9. 游戏内可视化配置、JEI / REI 查询与数据包联动

### 9.1 游戏内可视化规则配置（4 种打开方式 + 6 大分类 + 适用性联动校验）
- **4 种便捷打开入口**：
  1. **雕纹附魔台界面右上角 `⚙` 齿轮按钮**（`btn_config.png`，紧邻《纂刻秘典》按钮左侧）：以容器内模态浮层打开，**不关闭附魔台容器、台内物品不掉落**，保存后当前附魔台列表与书架门槛立即刷新生效；
  2. **《纂刻秘典》顶部导航栏 `[⚙ 配置]` 按钮**：查阅指南时可一键切入配置界面；
  3. **ModMenu 模组列表「配置」按钮**：安装 ModMenu 时自动注册配置入口（未安装 ModMenu 时零前置正常运行）；
  4. **指令系统**：客户端输入 `/cet config` 直接打开配置面板；服务端管理员支持 `/cet reload-config`（从磁盘热重载并全服同步）与 `/cet reset-config`（一键恢复全部默认值并全服同步）。
- **6 大逻辑分类（共 55 项细粒度配置）**：
  1. **通用与原版兼容**：数据包覆盖优先级（`override_datapacks`）、附魔书堆叠上限（`1..64`，标注 `⟳ 需重启游戏`）、原版附魔台行为规则、铁砧平摊累积惩罚开关、同名同级合书引导开关；
  2. **书架与呼吸空间**：普通木书架进度阶梯总开关、白板直附上限模式、满阶书架数、水平/垂直扫描半径、台周防实心埋台呼吸空间开关及最少通透格数、无遮挡视线开关；
  3. **母本与附魔经济**：雕纹母本消耗模式（充能损耗 / 永久保留 / 单次消耗）、最大充能数、拓印消耗、耗尽降阶/残卷行为、母本耐久自动温养回复总开关及 `38` / `42` 两档书架阈值与回复间隔、普通书架与藏书馆总减免上限、双书合并与单书进修开关及经验倍率；
  4. **宝藏顿悟系统**：解锁书架门槛、基础/封顶触发概率、最大槽位数、自动轮换秒数、锁定/重刷等级消耗与锁定累计时长；
  5. **退魔与物品置换**：退魔洗练总开关、本台溯源与外来折算返还比例、单洗最低/最高等级、破除诅咒开关与消耗等级、稀有置换探索前置开关、褪魔残卷三阶段门槛、物品置换单次最大批量（`1..64`）；
  6. **世界结构与战利品**：遗迹宝箱附魔书策略、自然结构雕纹书架藏书开关、最少/最多藏书数与附魔书概率（标注 `🗺 新区块/新开箱`）。
- **智能适用性逻辑与多人权限同步**：
  - **7 条父子适用性链路**：当父级总开关关闭或父级模式不匹配时（例如关闭「要求台周呼吸空间」、或将「母本消耗模式」设为「永久保留」、或关闭「启用退魔洗练总开关」导致子项与「破除诅咒消耗」两级联动失效），子配置项自动置灰锁定并直观提示生效前提，同时保留原数值不丢失；
  - **跨字段一致性约束**：拖动滑块时自动维护上下界与经济守恒关系（如 `阶段一 ≤ 阶段二 ≤ 满阶书架`、`木书架减免 ≤ 总减免上限`、`外来返还 ≤ 本台溯源返还`、`最少藏书 ≤ 最多藏书`、扫描总体积上限保护）；
- **数据包优先原则与服务器 / 整合包防篡改锁定机制（`pack_policy.json`）**：
  - **默认严格「数据包优先于游戏内配置」（`override_datapacks = false`）**：任何外部数据包（存档 `datapacks/`、KubeJS、Paxi、OpenLoader 或附属核心模组 JAR）中显式声明的配置项，默认**无条件优先于玩家的 `config/chiseled_enchanting_table.json` 与游戏内面板修改**；被数据包接管的条目会在面板中自动锁定并注明 `📦 当前由外部数据包优先接管生效`，未被数据包涉及的其他选项仍允许玩家自由微调；
  - **多人服务器防作弊保护**：所有附魔花费、书架判定、母本损耗/回复、宝藏顿悟、退魔返还与战利品全部 **100% 服务端权威计算**；普通玩家无 `GAMEMASTERS` / `chiseled_enchanting_table:config/manage` 权限时，本地修改 `config/*.json` 或伪造发包均完全无效，服务端会直接拦截并重推权威规则；
  - **整合包单人防私改策略（`data/chiseled_enchanting_table/chiseled_enchanting_table/pack_policy.json`）**：整合包作者可在 KubeJS（`ServerEvents.highPriorityData`）、Paxi 或自定义核心模组 `.jar` 中覆盖 `pack_policy.json`：
    - `"enforce_datapack_priority": true`：强制锁死数据包最高优先级，即便玩家手动用记事本把 `config/chiseled_enchanting_table.json` 中的 `"override_datapacks"` 改为 `true` 也无法覆盖数据包；
    - `"lock_in_game_config": true`（或按需指定 `"locked_keys": [...]`）：将全部（或指定核心平衡项）彻底锁定为 `🔒 整合包 / 服务器统一配置已锁定（只读检视）`，单人存档面板与 `config/*.json` 外部改档均不再覆写整合包设定。

### 9.2 JEI / REI 双向查询与底层数据包表
- **可选客户端联动（无硬前置）**：安装 JEI 或 REI 时自动注册 **「纂刻附魔」** 与 **「纂刻置换与退魔」** 分类，专用服配置与自定义数据包自动通过 `EnchantCostTablePayload` 同步到客户端界面、秘典图解与 JEI / REI。
- **底层数据包（Datapack）单源表**（`data/chiseled_enchanting_table/chiseled_enchanting_table/`）：
  - `default_enchantments.json`：默认基础附魔与标签（兼容第三方模组 `#minecraft:in_enchanting_table`）
  - `enchantment_costs.json`：各附魔基础经验与多材料递增曲线
  - `book_upgrades.json`：双书合并（`0.6×`）与单书升级（`1.4×`）倍率及专属材料表
  - `library_resonance.json`：普通书架、雕纹藏书与宝藏亲和度全部减免与成长参数
  - `treasure_epiphany.json`：宝藏顿悟书架门槛（`32`）、概率、刷新周期（`12000 ticks`）、锁定/刷新花费与宝藏材料表
  - `disenchanting.json`：退魔总开关、破咒开关、`xp_refund_scale` 及单洗/破咒原版与模组多选耗材表
  - `shelf_gates.json`：`7×5×7` 扫描范围、普通书架升级曲线（锚点 `38`，$\gamma = 1.25$）与褪魔残卷 4 档恢复配置
  - `item_transformations.json`：自定义物品置换配方（支持 `#tag` 标签输入、保底门槛与扣级数独立配置）
  - `bookshelf_book_pool.json` & `loot_injections.json`：遗迹雕纹书架与战利品箱附魔书生成池
