## 1. 三步上手

1. **放置附魔台与书架**：以纂刻附魔台为中心，周围 **`7 × 5 × 7`**（水平各 `3` 格、上下各 `2` 格）范围内的**普通书架**与**雕纹书架**都会自动计入。
2. **放入目标与材料**：
   - **上槽（目标格）**：放入需要附魔的装备、普通书、附魔书，或可置换的物品（如金苹果、钻石剑、玻璃瓶等）。
   - **下槽（材料格）**：放入主耗材（青金石、绿宝石、紫水晶碎片等，支持看图标轮播任选一种）。若条目带有第二种/第三种辅料，直接放在**背包内**即可自动扣除。
3. **点击左侧列表词条**：满足材料与等级条件即可直接附魔或置换，**不会像铁砧那样累积任何「过多操作（Too Expensive）」惩罚**。

## 2. 合成与获取配方

### 2.1 纂刻附魔台（2 种合成路线）
- **直接合成**：上方 `1× 书`，中排 `钻石 + 雕纹书架 + 钻石`，底排 `3× 哭泣的黑曜石`。
- **原版附魔台升级**：上方 `紫水晶碎片`，中排 `紫水晶碎片 + 原版附魔台 + 紫水晶碎片`（四角或十字），搭配 `雕纹书架 + 哭泣的黑曜石` 升级合成。
- **个性化染色**：手持任意原版染料右键已放置的纂刻附魔台，可为台布混合染色（破坏掉落保留颜色）。

### 2.2 哭泣的黑曜石（新增量产配方）
- **有序合成**：外圈 **`8× 黑曜石`** 围住中心 **`1× 恶魂之泪`** $\longrightarrow$ 产出 **`8× 哭泣的黑曜石`**。

### 2.3 秘法凝晶（`chiseled_enchanting_table:arcane_catalyst`）
- 由 `钻石块、绿宝石块、金块、紫水晶块、青金石块、哭泣的黑曜石` 合成的高阶通用触媒，可在**宝藏顿悟、附魔书材料升级、冻结锁定**中直接作为单件替代耗材使用。

## 3. 双轨书架与经验减免机制

扫描范围统一为附魔台周围 **`7 × 5 × 7`**（共 244 个邻近方块位），普通书架与雕纹书架各司其职、互不替代：

### 3.1 普通书架（数量 $W$）
- **常规魔咒等级推进**：将所有常规附魔台魔咒（`#minecraft:in_enchanting_table`，不含宝藏与诅咒）从 `1` 级随书架数提升至**中阶上限 $\lceil M_e / 2 \rceil$**（例如最高 5 级的锋利最多推至 `III` 级；满级需靠雕纹书架母本）。
- **经验减免（满 `12` 个起效）**：
  $$\Delta_{\text{木书架}}(W) = \begin{cases} 0\%, & W < 12 \\ \min\!\bigl(12\%,\; 2\% + \lfloor (W - 12)/2 \rfloor\%\bigr), & W \ge 12 \end{cases}$$
  （`12` 个 = `-2%`，至 `32` 个达到木书架上限 **`-12%`**。）
- **唤醒宝藏顿悟**：当 **$W \ge 32$** 时，激活右上角「宝藏顿悟」系统。

### 3.2 雕纹书架母本（相对品阶 $r(e) = L_e / M_e$，自动兼容任意模组魔咒）
- **1:1 无损解锁母本**：把任意附魔书放进范围内的雕纹书架，即永久解锁该魔咒 `1 ~ L` 级（书本留在书架内**不消耗**）。
- **相对品阶权重**：对每种已存魔咒 $e$（最高等级 $M_e$，书架内最高等级 $L_e$），按相对比例 $r(e) = \min(1, L_e / M_e)$ 折算完本权重：
  $$w(e) = 0.45\,r(e) + 0.55\,r(e)^2, \qquad E_{\text{总}} = \sum_e w(e)$$
- **双重经验减免（总上限 `-40%`）**：
  1. **公共减免**：$\Delta_{\text{公共}} = \min(25\%, \; \Delta_{\text{木书架}}(W) + \min(13\%, \operatorname{round}(1.5\,E_{\text{总}})\%))$，对全表生效；
  2. **同种母本专属减免**：若雕纹书架中存有该魔咒母本，额外获得 $\Delta_{\text{专属}}(e) = \operatorname{round}(15\% \cdot r(e)^{1.5})$，叠加后单条最高可达 **`-40%`**！

| :--- | :---: | :--- | :--- |
| **原版附魔台量产模式** | **1 / 2 / 3 颗绿色经验球** + `Lv.X` | ① **所有雕纹书架母本已覆盖的附魔**<br>② **所有物品置换配方** | 玩家当前等级需达到门槛 `Lv.X`（最高 30 级，享受书架最高 `-40%` 门槛减免），但**点击后仅扣除 `1 / 2 / 3` 级经验**（保留经验条进度条百分比）！例如满减免下 `锋利 V` 门槛降至 `18` 级，玩家在 `30` 级可连续量产 **5 把** 满配剑（`30 → 27 → 24 → 21 → 18`）。 |

| **附魔书直接转移** | 绿色 `0L` | 上槽放装备/书 + 下槽直接消耗一本附魔书 | **0 经验消耗**（但会消耗下槽那本附魔书并留下残卷）。 |

## 5. 材料消耗曲线与多选支付

- **多材料自由任选**：常规附魔与升级不强制绑定单一矿产，青金石、绿宝石、紫水晶碎片等可在材料格任意选一种支付（悬停在主材料图标上可查看全部可用替代方案）。
- **随魔咒等级平滑递增 & 按稀有度差异化定量**：
  - 高产出材料（如青金石 `3 → 20`、新版本绿宝石 `2 → 18`）单次需求数高于低产出材料（如紫水晶碎片 `1 → 8`）；
  - 单级魔咒（`maxLevel = 1`）自动取中位档，多级魔咒（兼容任意模组 `maxLevel`）随等级平滑增长。
- **母本宝藏免双材料**：雕纹书架中已存有母本的宝藏魔咒，日常给装备附魔**只需普通单材料**；只有尚未拥有母本、通过「宝藏顿悟」铭刻时才需要双材料（或 `1× 秘法凝晶`）。

## 6. 附魔书培养闭环（堆叠、升级与残卷覆写）

1. **附魔书支持 64 堆叠**：本模组将原版 `minecraft:enchanted_book` 最大堆叠上限提升至 **`64`**，方便整理归档。
2. **附魔书升阶（2 种途径）**：将未满级的附魔书放入上槽：
   - **合并升级（`合并：...`）**：下槽放入一本同魔咒同等级的附魔书，消耗经验升至下一级（例如 `锋利 III + 锋利 III → 锋利 IV`）。
   - **材料升级（`升级：...`）**：没有第二本同级书时，直接在下槽放入对应耗材 + 经验直接突破至下一级。
3. **褪魔残卷与「空白覆写」**：
   - 当附魔书被合并消耗或剥离魔咒后，会留下可 64 堆叠的 **`褪魔残卷（depleted_tome）`**（同时自动识别旧存档残留空组件书），避免污染正常普通书堆叠。
   - 将残卷放入上槽（单次最多叠放 `8` 本），消耗 **1 级经验**（门槛 `Lv.1`）与任意常见材料（纸 / 骨粉 / 青金石 / 绿宝石 / 墨囊 / 发光墨囊 / 紫水晶碎片），点击 **`覆写：书`** 即可还原为纯净的原版普通书。

## 7. 宝藏顿悟、锁定与手动刷新

当周围普通书架 **$W \ge 32$** 时解锁，专门解决「经验修补、无限（或无母本宝藏）、迅捷潜行、风爆」等宝藏魔咒的获取与升阶：

- **出现概率与同出数量**（随普通书架数、雕纹书架总品阶、以及与当前目标物品匹配的同系母本品阶共同提升）：
  - **触发概率**：基础 `28%`，最高提升至 **`90%`**；
  - **单件同时刷出上限**：基础 `1` 条，随书库扩建最高同一件装备/书可同时刷出 **`4` 条** 宝藏词条！
  - **多级宝藏进修**：若某多级宝藏魔咒（如迅捷潜行 `I`）未满级，仍可继续顿悟刷出更高阶直至满级！
- **右上角控制面板**：
  - **自然轮转**：每 `10` 分钟自动刷新一次，或每次未锁定时完成附魔后自动推进。
  - **锁定按钮（左，蓝色锁图标）**：消耗经验与材料（背包有即可自动扣），每次延长锁定时间（上限 `30` 分钟），锁定期间可安心去准备双材料，**挖下并重新放置附魔台也会完整保留锁定状态与剩余时间**。
  - **刷新按钮（右，紫色法阵图标）**：消耗少量经验与单材料立即重刷当前顿悟词条。

## 8.5 差额升阶减免与「退魔 · 洗练」双标签页系统

### （1）已有低级附魔直接升阶（`L_cur → L_new`）自动差额减免
无论是**附魔书**还是**已附魔装备**，只要目标本身已带有同种低等级附魔（`1 ≤ L_cur < L_new`），在顶部 **「铭刻 · 升阶」** 页直接点击更高阶词条时，系统会自动扣除先前等级已投入的成本：
- **材料差额折算**：按 `max(1, Cost(L_new) - Cost(L_cur))` 计算净增耗材，并额外享受 **雕纹母本 `-20%`** 或 **`≥12` 木书架 `-10%`** 引导折扣；对附魔书 `+1` 升阶同时封顶不高于研究升级花费，并自动合并重复条目。
- **经验差额折算**：若雕纹书架已存有对应母本，跨阶升级仅扣 **`1~2` 级**且等级门槛按净增比例下调；无母本直升则按 `XP(L_new) - XP(L_cur)` 差额扣减并叠加最高 `-40%` 书库共鸣减免。
- **防误降级保护**：「铭刻 · 升阶」页自动隐藏所有低于当前等级的条目，避免误花材料把高等级词条覆盖降级。

### （2）顶部「退魔 · 洗练」页：四大退魔操作与新物品 `退魔砂`
点击附魔台左上角 **「退魔 · 洗练」** 标签页（支持 `Shift+左键` 快捷放入任何带附魔物品，含盾牌、鞘翅、雕刻南瓜等）：

| 操作类型 | 材料消耗 | 经验变化 | 效果说明 |
| :--- | :--- | :---: | :--- |
| **✦ 全部洗去**（列表首行 / 右侧一键按钮） | **0 材料** | **返还 `+XP` 点数** | 一次性洗去所有**非诅咒**附魔并返还全部精华经验；无诅咒附魔书直接还原为**普通书** |
| **逐级 / 跨级降级**（如 `锋利 V → IV / III / I`） | **0 材料** | **返还 `+XP` 点数** | 按等级势能差 `V(L_cur) - V(L_target)` 精确返还经验点；**分步降级总和与一步全洗完全相等，绝无刷经验漏洞** |
| **定向单洗**（`抹除：XXX`，多词条时出现） | `1~3× 退魔砂` / `发光墨囊+石英` / `燧石+骨粉` / `1× 秘法凝晶` | 需 `Lv.6~14` · **扣 1~2 级** | 精准抹除选中的那一条废词条，**完整保留装备或附魔书上的其余所有附魔** |
| **破除诅咒**（`破除诅咒：绑定 / 消失诅咒`） | `2× 退魔砂 + 1× 恶魂之泪` / `1× 秘法凝晶` / `2× 恶魂之泪 + 1× 金苹果` | **完整消耗 `12` 级**（受书库最高 `-40%` 减免） | 净除 `#minecraft:curse` 标签下的原版或模组诅咒，同时保留其余全部正常附魔 |

- **`退魔砂`（`chiseled_enchanting_table:cleansing_grit`）无序合成配方**：`1× 燧石 + 1× 下界石英 + 1× 发光墨囊 + 1× 骨粉 → 4× 退魔砂`。
- **100% 第三方附魔模组与多版本（`26.1.2 → 26.2 → 26.3+`）兼容**：返还经验公式与单洗阶梯完全基于注册表动态读取的相对等级 `r = L / maxLevel`（自动适配 `maxLevel = 1..255`）、`Enchantment.anvilCost()` 对数平滑因子与 `#minecraft:treasure` / `#minecraft:curse` 原生标签计算，无任何硬编码魔咒 ID，且不新增任何脆弱 Mixin。

## 9. JEI / REI 双向查询与数据包配置

- **可选联动（无需前置）**：客户端安装 JEI 或 REI 时自动注册 **「纂刻附魔」** 与 **「纂刻置换」** 两大分类；不装也能独立运行。
- **全部数值支持数据包（Datapack）覆盖**：位于 `data/chiseled_enchanting_table/chiseled_enchanting_table/`：
  - `default_enchantments.json`：默认基础魔咒与标签（默认兼容第三方模组 `#minecraft:in_enchanting_table`）
  - `enchantment_costs.json`：各魔咒经验与渐进材料曲线
  - `book_upgrades.json`：附魔书合并/材料升级开关与花费
  - `treasure_epiphany.json`：宝藏顿悟书架门槛、概率参数、锁定/重刷花费与专属材料表
  - `disenchanting.json`：退魔系统总开关、诅咒破除开关、经验返还倍率 `refund_scale`、定向单洗与诅咒破除多选耗材表
  - `item_transformations.json`：自定义物品置换配方（自动同步至客户端 UI 与 JEI / REI）
  - `bookshelf_books.json` & `loot_injections.json`：遗迹雕纹书架与战利品箱附魔书生成池

## 10. 与原版上游模组（Sacramentix）完整差异对照表

本分支基于原版 [Sacramentix/chiseled-enchanting-table](https://github.com/Sacramentix/chiseled-enchanting-table)（MIT 协议）移植至 **Minecraft 26.1.2**，并对游戏体验、经济曲线、UI 与跨模组兼容性做了系统性重构：
