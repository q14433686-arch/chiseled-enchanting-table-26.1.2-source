## 1. 三步上手

1. **放置附魔台与书架**：以纂刻附魔台为中心，默认周围 **`7 × 5 × 7`**（水平各 `3` 格、上下各 `2` 格，共 `244` 格，可在 `shelf_gates.json` 自定义且自动限制总体积上限 `2048` 格）范围内的**普通书架**（标签 `#chiseled_enchanting_table:regular_bookshelves` 或原版 `#minecraft:enchantment_power_provider`）与**雕纹书架**都会自动计入。
2. **放入目标与材料**：
   - **上槽（目标格）**：放入需要附魔的装备、普通书、附魔书，或可置换的物品（如金苹果、钻石剑、玻璃瓶、褪魔残卷等）。
   - **下槽（材料格）**：放入主耗材（青金石、绿宝石、紫水晶碎片等，支持看图标轮播任选一种）。若条目带有第二种/第三种辅料，直接放在**背包内**即可自动扣除。
3. **点击左侧列表词条**：满足材料与等级条件即可直接附魔、升阶、退魔或置换，**不会像铁砧那样累积任何「过多操作（Too Expensive）」惩罚**。

## 2. 合成与获取配方

### 2.1 纂刻附魔台（2 种合成路线）
- **直接合成**：上方 `1× 书`，中排 `钻石 + 雕纹书架 + 钻石`，底排 `3× 哭泣的黑曜石`。
- **原版附魔台升级**：上方 `紫水晶碎片`，中排 `紫水晶碎片 + 原版附魔台 + 紫水晶碎片`（四角或十字），搭配 `雕纹书架 + 哭泣的黑曜石` 升级合成。
- **个性化染色**：手持任意原版染料右键已放置的纂刻附魔台，可为台布混合染色（破坏掉落保留颜色；未冻结且未染色时掉落物保持纯净零 NBT 组件以便堆叠）。

### 2.2 哭泣的黑曜石（新增量产配方）
- **有序合成**：外圈 **`8× 黑曜石`** 围住中心 **`1× 恶魂之泪`** $\longrightarrow$ 产出 **`8× 哭泣的黑曜石`**。

### 2.3 秘法凝晶（`chiseled_enchanting_table:arcane_catalyst`）
- 由 `钻石块、绿宝石块、金块、紫水晶块、青金石块、哭泣的黑曜石` 合成的高阶通用触媒，可在**宝藏顿悟、附魔书材料升级、定向单洗、破除诅咒、冻结锁定**中直接作为单件替代耗材使用（退魔与去诅咒同时保留纯原版材料方案，绝不硬锁此物品）。

### 2.4 纂刻秘典（`chiseled_enchanting_table:arcane_grimoire` · 游戏内图解说明书）
- **无序合成配方一（书架拓印）**：`1× 书与笔（minecraft:writable_book）` + `1× 雕纹书架（minecraft:chiseled_enchanting_table / minecraft:chiseled_bookshelf 原版雕纹书架）` $\longrightarrow$ `1× 纂刻秘典`。
- **无序合成配方二（残卷重装）**：`1× 褪魔残卷（chiseled_enchanting_table:depleted_tome）` + `1× 墨囊（minecraft:ink_sac）` $\longrightarrow$ `1× 纂刻秘典`。
- **收纳与快捷查阅**：已加入 `#minecraft:bookshelf_books` 标签，可直接放入雕纹书架收纳展示；也可直接在**纂刻附魔台界面右上角书典按钮**一键翻阅并一键返回附魔界面，内置全交互合成表、书架模拟器、双经验条、升阶/顿悟/置换/退魔全图解及独立翻书音效。

## 3. 三轨书架与经验减免机制

默认扫描范围为附魔台周围 **`7 × 5 × 7`**（`244` 格），普通书架与雕纹书架各司其职、互不替代：

### 3.1 普通书架（标签 `#chiseled_enchanting_table:regular_bookshelves`，数量 $W$）
- **三轨职责分离（白板中阶封顶 + 已附魔升阶解锁 + 雕纹母本直附毕业，曲线指数 $\gamma = 1.25$）**：
  - **轨道 1（白板物品 / 普通书直附）**：常规附魔类别（`#minecraft:in_enchanting_table`，自动排除 `#minecraft:curse`、`#minecraft:treasure` 与 `#chiseled_enchanting_table:epiphany_exclusive`）默认解锁 **`I` 级（`0` 书架）**；仅靠普通书架在白板物品上最高直接铭刻至中阶 $\lceil M / 2 \rceil$（如 `V` 系直附至 `III`、`IV` 系直附至 `II`，可通过 `blank_max_tier_mode` 切换）。
  - **轨道 2（已有词条升阶 / 附魔书材料研究升阶，`0 ~ 38` 架 → `I ~ MAX`）**：一旦装备或附魔书已持有某词条 `L ≥ 1`，周围普通书架按统一幂律曲线 $\gamma = 1.25$ 放开升阶上限直至 **`38` 架解锁满级 `MAX`**：
    $$W_{\text{req}}(L, M) = \begin{cases} 0, & M \le 1 \text{ 或 } L \le 1 \\ 38, & L \ge M \\ \operatorname{round}\!\left(38 \cdot \left(\dfrac{L - 1}{M - 1}\right)^{1.25}\right), & 1 < L < M \end{cases}$$
    - **最高 `2` 级系**（击退、火焰附加、冲击等）：`I(0)` → **`II(38)`**
    - **最高 `3` 级系**（耐久、时运、抢夺、忠诚、激流等）：`I(0)` → **`II(16)`** → **`III(38)`**
    - **最高 `4` 级系**（保护、摔落缓冲、穿透、破甲等）：`I(0)` → **`II(10)`** → **`III(23)`** → **`IV(38)`**
    - **最高 `5` 级系**（锋利、亡灵杀手、效率、力量、穿刺、致密等）：`I(0)` → **`II(7)`** → **`III(16)`** → **`IV(27)`** → **`V(38)`**
    - **高阶模组魔咒分档规则**：当 $1 \le M \le 39$（不超过 `38 + 1 = 39` 个整数架位状态）时，每一级均具有**严格单调递增**的书架门槛；当 $M \ge 40$（如 `maxLevel = 40 ~ 255`）时，离散架位 `0..38` 共 `39` 档，系统按上述幂律曲线将 `1..M` 均匀映射到全部 `39` 个书架档位（每增加 `1` 架平滑解锁一段连续等级区间，直至 **`38` 架解锁 `MAX`**），避免低阶大段挤在同一架位。
- **木书架经验减免（默认满 `12` 架起效、`38` 架满额，由 `library_resonance.json` 驱动并实时 S2C 同步）**：
  $$\Delta_{\text{木书架}}(W) = \begin{cases} 0\%, & W < 12 \\ \operatorname{round}\!\left(1\% + 14\% \cdot \operatorname{clamp}\!\left(\dfrac{W - 12}{38 - 12},\; 0,\; 1\right)\right), & W \ge 12 \end{cases}$$
  （`12` 架 = **`-1%`**，至 **`38` 架**达到木书架满额上限 **`-15%`**，与升阶满级锚点 `38` 架同步毕业。）
- **唤醒宝藏顿悟 & 实时书架同步**：当 **$W \ge 32$** 时激活右上角「宝藏顿悟」系统；界面打开期间拆装书架或增减藏书会通过 `LiveShelfStatePayload` 实时刷新，无需重开界面。

### 3.2 雕纹书架母本（相对品阶 $r(e) = L_e / M_e$，按魔咒 ID 去重统计）
- **轨道 3（1:1 无损解锁母本）**：把任意附魔书放进范围内的雕纹书架，即永久解锁该魔咒 `1 ~ L` 级（书本留在书架内**不消耗**，白板装备也可直接铭刻至母本等级）。
- **相对品阶权重（`chiseled_mastery`）**：对每种已存非诅咒魔咒 $e$（按魔咒 ID 去重取最高已存等级 $L_e$，最高等级 $M_e$），按相对比例 $r(e) = \min(1, L_e / M_e)$ 计算精通单位：
  $$w(e) = r(e)^{1.25}, \qquad E_{\text{总}} = \sum_{e \notin \text{curse}} w(e)$$
- **双重经验减免（总上限 `-40%`）**：
  1. **公共减免**：
     $$\Delta_{\text{全局母本}} = \min\!\bigl(20\%,\; \lfloor 1.25 \cdot E_{\text{总}} \rfloor\%\bigr), \qquad \Delta_{\text{公共}} = \min\!\bigl(35\%,\; \Delta_{\text{木书架}}(W) + \Delta_{\text{全局母本}}\bigr)$$
  2. **同种母本专属减免**：若雕纹书架中存有该魔咒母本，额外获得线性专属减免：
     $$\Delta_{\text{专属}}(e) = \operatorname{round}\!\bigl(15\% \cdot r(e)^{1.0}\bigr), \qquad \Delta_{\text{总}}(e) = \min\!\bigl(40\%,\; \Delta_{\text{公共}} + \Delta_{\text{专属}}(e)\bigr)$$

## 5. 材料消耗曲线与多选支付

- **多材料自由任选**：常规附魔与升级不强制绑定单一矿产，青金石、绿宝石、紫水晶碎片等可在材料格任意选一种支付（悬停在主材料图标上可查看全部可用替代方案及多材料组合）。
- **随魔咒等级平滑递增 & 按稀有度差异化定量**：
  - 高产出材料（如青金石 `3 → 20`、绿宝石 `2 → 18`）单次需求数高于低产出材料（如紫水晶碎片 `1 → 8`）；
  - 单级魔咒（`maxLevel = 1`）自动取中位档，多级魔咒（兼容任意模组 `maxLevel = 1..255`）随等级平滑增长。
- **母本宝藏免双材料**：雕纹书架中已存有母本的宝藏魔咒，日常给装备附魔**只需普通单材料**；只有尚未拥有母本、通过「宝藏顿悟」铭刻时才需要双材料（或 `1× 秘法凝晶`）。

## 6. 附魔书培养闭环（堆叠、升级与残卷覆写）

1. **附魔书堆叠上限可配置（默认 `64`）**：通过 Fabric 原生 `DefaultItemComponentEvents.MODIFY` 将 `minecraft:enchanted_book` 默认堆叠上限设为 **`64`**，并可在 `config/chiseled_enchanting_table.json` 中自由调整为 `1 ~ 64`。
2. **附魔书升阶（2 种途径）**：将未满级的附魔书放入上槽：
   - **合并升级（`合并：...`）**：下槽放入一本同魔咒同等级的附魔书，不受普通书架数量限制，按 `book_upgrades.json` 的 **`0.6×` 经验系数**（与差额成本取较小值）扣除经验，耗尽的副书转化为 `1×` 褪魔残卷。
   - **材料研究升级（`升级：...`）**：不消耗第二本附魔书、直接投入耗材升阶，受普通书架 `0 ~ 38` 阶梯（或已存雕纹母本等级）约束。
3. **褪魔残卷与三梯度「空白覆写」线性批量恢复系统**：
   - 合格高阶藏书判定按**去重后的不同非诅咒魔咒种类数 $H$** 统计（$M = 1 \Rightarrow 1$，$M = 2 \Rightarrow 2$，$M \ge 3 \Rightarrow M - 1$，复制存放同一种书不会重复刷数）：
     - **未达梯度（$W < 8$）**：按批次本数 $B \in [1..8]$ 严格线性计价，每本需 `Lv.1` 扣 `1` 级 + `2×` 覆写材料（`纸 / 骨粉 / 青金石 / 绿宝石 / 墨囊 / 发光墨囊 / 紫水晶碎片` 任选）。
     - **梯度一（$8 \le W < 18$）**：**免除全部经验损耗（`0` 经验）**，仅按本数消耗 `2×` 覆写材料（单次最多 `8` 本）。
     - **梯度二（$W \ge 18$ 且 $H < 6$）**：**免除经验损耗 + 覆写材料减半**（每本 `1×` 材料，单次最多 `8` 本）。
     - **梯度三（$W \ge 18$ 且 $H \ge 6$）**：**`0` 经验 + `0` 材料完全免费恢复为普通 `书`**（单次支持整组 **`64` 本**一键批量转化）！

## 7. 宝藏顿悟、锁定与手动刷新

当周围普通书架 **$W \ge 32$** 时解锁，专门解决「经验修补、无限、迅捷潜行、风爆」等宝藏魔咒的获取与升阶：

- **亲和度与触发公式（`epiphany_affinity`，全参数由 `library_resonance.json` 驱动）**：
  - 记 $E_{\text{总}}$ 为雕纹书架全部非诅咒母本精通和，$E_{\text{亲和}}$ 为当前目标物品可附魔母本精通和；当目标槽放入**普通书（`minecraft:book`）**时，全部非诅咒母本按 **`0.50×` 权重**（`blank_book_affinity_weight = 0.50`）计入 $E_{\text{亲和}}$；
  - 触发概率有效精通：$E_{\text{prob}} = 0.45 \cdot E_{\text{总}} + 0.85 \cdot E_{\text{亲和}}$，触发率 `28% ~ 90%`；
  - 槽位与进修分：$S = (W - 32) \cdot 1.0 + 2.2 \cdot E_{\text{总}} + 3.5 \cdot E_{\text{亲和}}$，单件最高同时刷出 **`4` 条** 宝藏词条，且多级宝藏可一路进修至满级！
- **右上角控制面板**：
  - **自然轮转**：默认每 `10` 分钟（`cycle_ticks = 12000`，双端动态同步）刷新一次，未锁定时完成铭刻后自动推进。
  - **锁定按钮（左）**：消耗经验与材料延长锁定时间（上限 `30` 分钟），破坏并重放附魔台完整保留锁定状态。
  - **刷新按钮（右）**：消耗少量经验与单材料立即重刷当前顿悟词条。

### 8.2 顶部「退魔 · 洗练」页：归纳守恒返还与四大洗练操作（`disenchanting.json`）

| 操作类型 | 材料消耗 | 经验变化 | 效果说明 |
| :--- | :--- | :---: | :--- |
| **✦ 全部洗去** | **0 材料** | **台面涌出 `+XP` 经验球** | 一次性洗去所有**非诅咒**附魔并返还精华点数；清空词条的附魔书化为**褪魔残卷** |
| **逐级 / 跨级降级** | **0 材料** | **台面涌出 `+XP`（或 `0 XP`）** | 按归纳势能差 `V(L_cur) - V(L_target)` 返还；对超高阶模组魔咒（如 `maxLevel = 255`），因整数点量化部分相邻单级差为 **`0 XP`**（界面明确显示 `0 XP`），跨多级降级仍按总势能差完整返还，且严格满足 `V(k) - V(a) <= minStepCost(a → k) - 5` 零套利上界 |
| **定向单洗** | `1~3× 退魔砂 + 青金石/发光墨囊/紫水晶` / **`1× 秘法凝晶`** / **`4~12× 紫水晶碎片 + 6~18× 青金石`** | 需 `Lv.4~10` · **扣 1~3 级**（单条词条时等同全洗返还 `+XP`） | 精准抹除选中的单条非诅咒词条，完整保留其余全部附魔 |
| **破除诅咒** | `3× 退魔砂 + 1× 恶魂之泪` / `2× 退魔砂 + 1× 金苹果` / **`1× 秘法凝晶`** / **`2× 恶魂之泪 + 2× 金苹果`** | **完整消耗 `12` 级**（受书库最高 `-40%` 减免） | 净除 `#minecraft:curse` 标签下的原版或模组诅咒，保留其余全部正常附魔 |

## 9. JEI / REI 双向查询与数据包配置

- **可选联动（无需硬前置）**：客户端安装 JEI 或 REI 时自动注册 **「纂刻附魔」** 与 **「纂刻置换」** 两大分类，专用服数据包覆盖通过 `EnchantCostTablePayload` 自动同步到客户端 UI 与 JEI / REI（未连接服务器时自动标记为本地默认参考值）。
- **全部数值支持数据包（Datapack）单源驱动**：位于 `data/chiseled_enchanting_table/chiseled_enchanting_table/`：
  - `default_enchantments.json`：默认基础魔咒与标签（默认兼容第三方模组 `#minecraft:in_enchanting_table`）
  - `enchantment_costs.json`：各魔咒经验与渐进材料曲线
  - `book_upgrades.json`：附魔书合并（`0.6×`）/ 材料研究升级（`0.85×`）开关与花费
  - `library_resonance.json`：`wooden_bookshelves`、`chiseled_mastery`、`epiphany_affinity` 三段共鸣与减免全参数（双端实时同步）
  - `treasure_epiphany.json`：宝藏顿悟书架门槛、概率参数、周期 `cycle_ticks`、锁定/重刷花费与专属材料表
  - `disenchanting.json`：退魔总开关、去诅咒开关、`xp_refund_scale`（`0.0 ~ 1.0`）及多选耗材表（无代码内硬编码副本）
  - `shelf_gates.json`：扫描范围 `scan_volume`、直附/升阶曲线（默认锚点 `38`、`gamma = 1.25`、`blank_max_tier_mode = "half_ceil"`、按魔咒 ID 覆盖表）与褪魔残卷三梯度及批量参数
  - `item_transformations.json`：自定义物品置换配方（支持 `#tag` 标签输入、`min_required_level` 门槛保底与 `deducted_levels` 扣级数独立配置）
  - `bookshelf_book_pool.json` & `loot_injections.json`：遗迹雕纹书架与战利品箱附魔书生成池

| 对比维度 | 上游原版（Sacramentix） | 本 26.1.2 增强版 |
| :--- | :--- | :--- |
| **游戏版本与架构** | 旧版 Minecraft，世界生成期曾存在区块死锁隐患 | 完整适配 **MC `26.1.2` + Java 25**，修复世界生成雕纹书架死锁，全配置 S2C 实时同步 |
