# 效率 × 精准采集：精准切片与样板连筑

> 下述是代码初版和待验收边界；当前尚待 26.1.2 编译及游戏实测。最终验收必须与其他方向在同一游戏进程内逐项记录通过、失败、跳过及原因。

## 载体与原版

两个方向在新融合书装载、直接融合、翻转及升级时接受可用的镐、斧、锹、锄、剪刀；不是机械取原版两附魔对象交集。工具须在主手才能操作；其他旧载体保留旧数据与旧效果，替换签名映射的数据包不强制套新版。原版支持的主位附魔继续参与原版结算；副位不写入原版附魔列表。剪刀的精准采集主位不被伪装成原版可附魔，不承诺剪刀获得原版未提供的精准采集掉落；其剪刀本来的采集行为仍走正常流程。

`G` 为可重绑定主动技能键，多个可用技能时用 `V` 切换。配置数值位于游戏内配置界面的对应签名条目，也可通过数据包和配置覆盖修改；以服务端生效配置为准。

## 效率 ▷ 精准采集：精准切片

主手持相应工具时按 `G` 循环选择水平面、东西竖面、南北竖面、关闭；默认关闭。成功挖掉中心方块之后，沿选中平面从中心四邻开始扩展，**只挖相连、方块类型和完整状态都相同的普通完整方块**。每格调用该玩家真实的 `ServerPlayerGameMode.destroyBlock`，继续执行权限、Fabric 破坏事件、原工具与其真实附魔、耐久及掉落；中心完成后再处理额外方块，工具丢失或损坏即停止。其他附魔的实际结算不凭空等同于副位精准采集。

额外数量 `min(slice_extra_cap, slice_extra_per_level × 效率等级)`：默认每级 6、上限 64；可分别设置每级 1–32 和总上限 1–256。未达总上限时与等级成正比。潜行暂停额外采掘，中心正常。避开方块实体、流体、不可破坏方块与非完整碰撞立方体；未加载区块、无权限或破坏事件取消的方块不能通过，并不会跨过它继续扩散。其他附魔或模组自身的方块更新仍可能产生连带世界变化，不能保证第三方逻辑的事务性。

## 精准采集 ▷ 效率：样板连筑

主手持相应工具并看向可触及的普通完整方块，按 `G` 保存其准确方块状态；再将对应材料放**副手**，看向起点方块的一个面并按 `G`，从该面沿法线逐格向外铺一条直线。潜行+G 可重新采样；样板绑定本次持有的工具和维度，60 秒后失效，不写进物品或存档。

每格检查区块已加载、边界、玩家权限、空目标、无方块实体的支撑位置，并预测本次普通放置是否与样板的完整状态一致；然后调用玩家的真实 `useItemOn`，触发 Fabric 使用事件与原版放置及物品消耗。每成功放置一格从副手实际材料扣一；材料不足、受阻、状态不一致或工具/材料被换掉即停止，**不会复制材料或覆盖原水**。为贯彻消耗要求，无限材料创造模式不触发。线条可从玩家触及的起点延伸超过普通手动触及距离，但逐格仍做权限检查。

数量 `min(line_blocks_cap, line_blocks_per_level × 效率等级)`：默认每级 4、上限 32；可设置每级 1–32 和总上限 1–256。普通方块当前限定无流体、无方块实体、完整碰撞立方体和标准 `BlockItem`，如普通石块、木板、轴向相符的原木；多格结构、自定义放置物品、容器和液体不复制。放置中的邻居更新可能改变最终状态；若第三方监听器修改世界或替换手中物品，不能安全回滚他人事务，故立即停止，不承诺第三方领地插件的所有自定义接口。
