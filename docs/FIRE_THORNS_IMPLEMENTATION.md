# 第 19 组：荆棘 × 火焰保护

> `43a53ba` 的任意目标修正版通过目标主/客户端/探针编译和 91 项 JUnit；游戏验收未进行，有限探针未运行。

## 行为和载体

融合书装书及直接融合均接受可损伤的实际穿戴护甲或手持盾牌；不按两附魔原版对象交集限制，剑和不可损物不接受。多件同时符合时按主手、副手、头、胸、腿、脚选择第一件作为状态来源；其他装备的普通护甲和独立附魔仍正常工作。

- **荆棘▷火焰保护·灼刺埋伏**：受到已造成真实生命值或吸收心损失的近战伤害时，标记那名攻击者，默认有效 120 tick。相同攻击者再次有效近战命中任意目标后，消费标记并延迟至当前攻击结束后的服务端 tick 反击：造成 `1 + 主位等级` 点荆棘伤害（上限 20）、引燃 3 秒，反伤成功时通过原版耐久与附魔流程消耗该件装备 2 点耐久，可正常损坏。首次、失效、完全格挡或被取消的攻击不凭空触发反击。非原版伤害类型不贸然识别为近战；原版玩家/生物攻击、长矛、重锤及蜂刺有明确判断。
- **火焰保护▷荆棘·隔焰荆帘**：火焰伤害经过抗性和真实附魔阶段时有实际减免，即在身边生成默认 80 tick 的短暂虚拟荆帘；每 5 tick 检查接触范围内可见合法敌人，每目标默认 20 tick 间隔，造成 `1 + 0.5×副位等级` 点荆棘伤害（上限 10）并引燃 2 秒。默认接触扩展为 `0.7 + 0.1×(副位等级−1)` 格，上限 3 格；每次至多处理最近 8 个目标，每帘最多记 64 个冷却目标。不放置或修改火方块。

标记与荆帘绑定玩家、维度和装备对象，装备暂放背包仍有剩余时间，但重新穿戴/持握到原槽位后才可再次反击或接触；掉落、融合变更、死亡、断线、换维度、过期都会清理。反击触发后若玩家死亡、装备已移除、攻击者不可伤害、换维度或不再加载则取消；标记自身跟随攻击者，在同一维度内不因远离或隔墙而凭空失效。图腾救回不是死亡，是否能继续还需游戏验收。范围目标排除盟友、村民、驯养生物、无敌者和未攻击玩家的中立生物，玩家对战遵守双向 PvP/队伍判断。`level.mayInteract` 和视线检查不能代替所有第三方领地插件。

## 原版与旧物

- 灼刺埋伏明确**替换该融合装备在上述原版近战中的即时荆棘 `POST_ATTACK`**：不先重复即时反伤再叠加一次延迟反伤；延迟伤害和耐久由此组合自己结算，因此该装备的自定义荆棘数据包 `POST_ATTACK` 在这些近战中也会被替换，不声称仍逐项执行。非近战、飞行物、未知 Mod 伤害类型及其他装备上的荆棘仍走原版；装备上同名独立荆棘与历史投影来源无法可靠区分，见其他旧数据迁移说明。
- 隔焰荆帘保留火焰保护主位：普通护甲走原版附魔迭代；非原生盾牌按真实数据包效果补偿一次，多个相关融合共享主位时按同一物品的主位最高等级去重；荆棘副位变为接触帘而非又叠加原版荆棘。异常或绕过附魔/效果的伤害不产生新反击/帘。
- 仅新支持载体停用旧 `pyro_thorns` 受击点燃击退及旧 `cinder_backlash` 清火抗火范围伤害；不适用旧物保留原数据、旧逻辑与旧载体提示。粒子/引燃只影响实体，不生成火方块。

## 验证边界

`FireThornsProbe` 准备了真实生物近战、事件取消、首次标记、攻击其他生物或穿戴者的第二击、延迟反击、普通耐久、盾牌火防数据包补偿、敌人与村民的有限检查，但手动重置生命/无敌时间并调用服务端 tick；不能代表自然间隔、键鼠、多玩家、客户端同步、真实图腾与第三方伤害/保护。玩家普通攻击/长矛、普通生物攻击与非玩家长矛另在原版攻击路径快照原有标记，兼容有效命中非生物实体及少数自定义生物伤害流程；第三方实体完全绕过这些路径且不走 `actuallyHurt` 时无法保证触发。近战 thorns `WrapMethod` 与其他 Mixin 的运行次序需要真实游戏确认；数据包或其他 Mod 的嵌套回调可能在伤害成功与扣耐久之间改动装备，不能保证跨 Mod 事务原子。
