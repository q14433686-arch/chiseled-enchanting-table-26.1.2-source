# 第 39.2 组：无限 × 耐久

> `5b022aa` 的目标版本构建及 JUnit 72/72 通过；**尚未游戏验收。** 数值由助手按此前已记录的方向自行选定，可通过游戏配置调整；目标编译及准备中的探针不能代替游戏实测。

## 回声取舍：无限 ▷ 耐久

- 新融合的两种装书途径只接受可正常损耗的弓或弩，保留可原生投影的无限；对不能使用无限的弩不伪造无限弹药。原版弹药、射击、其他互不冲突的附魔和耐久仍照常结算。
- 真实中央箭成功命中生物后，保存它实际采样的路径与该次伤害；持同一把装备时用可重绑定的主动技能释放一次回声。回声沿记录点逐 tick 飞行，是纯服务器逻辑和粒子，**不在世界生成或掉落可拾取箭**。它遇到新出现的墙、未加载区块、受保护目标或第一名碰撞对象即停止；目标若合法则受一次投射物类型的伤害，正常允许伤害事件取消，不重置无敌帧。默认伤害为原箭本次伤害的 60%，最多 100，可配置。
- 成功释放先向原武器发起默认 3 点真实耐久损耗，走原版 `hurtAndBreak`、附魔、耐久与损毁流程；已有独立耐久附魔正常可能免耗，不伪造固定扣点。剩余耐久不超过配置代价时为避免意外毁装拒绝释放。路径默认保存 200 tick，允许的采样上限 128 节点，超长、瞬移或中途丢失路径不生成残缺回声。每玩家最多保存 4 把武器的最近路径、同时飞行 2 道回声，服务端有总量上限。
- 路径只属于当前会话的玩家、维度和物品对象；换维、死亡、断线、失去物品或改变融合后失效，重启不保存。释放后不再需要继续持握，但玩家离开该维度或死亡时回声停止。

## 余韧续用：耐久 ▷ 无限

- 新融合只接受真正有耐久、单件可损耗的通用装备；无耐久或被设为不可损坏的物品不适用。可实际持握或穿戴的装备发生**真实耐久损耗**时，观察原版或数据包中该物品的耐久附魔实际免除的部分，不额外重掷一次概率；同时有其他增减损耗效果时，最多计入本次净免除量。主位原版耐久照常生效；对于确有耐久但不能原生投影耐久附魔的载体，调用真实数据包附魔效果一次。
- 默认每实际免除 4 点损耗积成一次可使用的储备，最多 3 次；默认自最近一次积累起 1,200 tick 过期，这些参数可配置。用主动技能预备后，该装备**下一次原版及其他附魔结算后仍大于零的耐久损耗操作**被整体免除并消耗一次储备；自然耐久免耗时不提前花掉预备，也不提高耐久上限。可再次选中同件装备取消预备，不消费储备。
- 多件装备同时有可用储备时，重复使用该技能按主手、副手、头、胸、腿、脚循环选择并切换该件的预备状态，提示当前装备名。资源只绑定玩家、维度、装备对象及融合内容；换维、死亡、断线、失去该物品或更换融合时清理，重启不保存。不以经验、不消耗其他装备，更不更改第 05 组的永久耐久上限。

## 兼容与待验收

- 不适用于新方向的旧载体保留原数据和旧效果；仅新有效载体关闭旧版无条件修复与自动轨迹回声，独立畸变和其他效果仍按原规则运行。数据包把原签名重映射到其他附魔时沿用旧分支，不擅自抢占。
- 回声只复现路径和一次伤害，不复刻特殊箭药水、穿透、方块改变、特殊弹体或所有原版投射物回调。伤害来源使用未加入世界的临时箭对象以保留投射物伤害类型和方向；第三方模组若要求伤害来源必须是已加入世界的实体，行为可能不同。对合法 PvP 保留正常世界/队伍检查；盟友、村民和驯服或有主生物受到保护。
- 耐久记录依赖目标版本 `ItemStack.processDurabilityChange` 与 `Enchantment.modifyDurabilityChange` 的 Mixin；另一个模组绕过原版流程或在效果调用后重新修改数值可能改变归因。预备中的代码、随机耐久、本地/远程键位、多装备轮选、取消/换手、死亡、弹道与新墙、客户端粒子、第三方领地和 PvP 仍须在完整实现后的单进程游戏验收中检查；多人及外部模组不能覆盖时如实 SKIP。
