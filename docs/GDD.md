> **项目定位**：面向 **Minecraft `26.1.2`（Fabric · Java 25）** 的独立原创「原版附魔+」模组

## 1. 设计铁律与核心定位

1. **绝不突破原版等级上限（No Level-Cap Inflation）**  
   全模组不存在 `锋利 VI`、`保护 X` 这类纯数值膨胀。所有输入附魔严格遵守原版等级上限（`I ~ V`），强度与乐趣 **100% 来自两个附魔合并后的机制化学反应**。
2. **顺序决定玩法（`[A ▷ B] ≠ [B ▷ A]`）**  
   同一个组合调换主次顺序，会诞生截然不同的两套流派——**前槽 `A` 为【体】（决定准入部位与触发载体），后槽 `B` 为【用】（注入异变机制或跨界效果）**。
3. **主词条守本分，副词条万物跨界（Grounded Host, Boundless Graft）**  
   主词条 `A` 必须是目标装备原版合法可附的附魔（保证剑还是剑、镐还是镐）；副词条 `B` **对全游戏所有附魔完全开放**（可以把靴子的 `冰霜行者`、三叉戟的 `激流`、重锤的 `风爆` 作为副词条融进剑、弓、镐或盾牌里）。
4. **独立成篇 + 自家生态闭环**  
   单独安装本模组即可通过纯原版材料畅玩 100% 内容；当同时安装 **《纂刻附魔台》(Chiseled Enchanting Table)** 时，两边在书架母本、触媒互通与「唯一破除异变词条圣所」上形成浑然天成的双模组联动。

## 2. 核心语法：有序体用与双层融合架构

### 2.1 二元有序融合结构 `[A(x) ▷ B(y)]`

- **固定二元链长**：每条融合词条严格由 **1 个主附魔 `A` + 1 个副附魔 `B`** 构成（记作 `[A ▷ B]`），不开放无限套娃 `[A ▷ B ▷ C]`，确保物品栏悬浮窗在 2 行以内清晰可读，且每个流派特征鲜明。
- **保留原主附魔基础能力**：融合成 `[A ▷ B]` 后，主附魔 `A` 原本的原版基础效果 **100% 保留**；副附魔 `B` 不直接照搬原版白字叠加，而是转化为挂载在 `A` 触发节奏上的**融合异变效果**。
- **单件装备防重复规则**：同一件装备上，任意单一附魔 ID 最多只允许出现一次（无论是独立存在，还是作为某条融合词条的 `A` 或 `B`），彻底杜绝「既挂一条独立 `锋利 V`，又挂一条 `[锋利 V ▷ 火焰附加 II]` 双倍吃锋利」的数值漏洞。
- **同种附魔不自融**：`A + A` 不产生融合（已满级提示「同源附魔无法融合」，未满级引导至铁砧/附魔台常规升阶）。

### 2.2 分级准入与等级成长规则

| 融合类别 | 定义范围 | 等级准入门槛 | 等级保留与后续补升规则 |
| :--- | :--- | :--- | :--- |
| **常规与跨界融合** | 原版彼此不互斥的同部位组合，或任意跨装备类别嫁接组合 | **任意等级可融**（如 `锋利 II ▷ 引雷 I`） | 保留各自输入等级 `[A(x) ▷ B(y)]`：主效果按 `x` 级结算，副载荷按 `y / B_max` 比例缩放。后续可在融合台放入更高等级的 `A` 或 `B` 附魔书**单独补升任一半边**至满级。 |
| **死敌互斥强融** | 原版存在硬互斥冲突的死敌组合（如 `无限 × 修补`、`时运 × 精准`、`多重 × 穿透`、`忠诚 × 激流`、`三大剑伤`、`四大保护`、`深海 × 冰霜`、`致密 × 破甲`） | **双方必须满级**（`x = A_max` 且 `y = B_max`） | 作为中后期毕业里程碑仪式；因为原版禁止共存，强行融合会产生 **「排斥失稳」**——不放稳定剂时有 **`35%` 概率扭曲为不可常规洗除的「畸融异变词条」**（详见第 6 节）。 |

## 3. 克制的「器魂」容量体系

> **设计原则**：保留「器魂」这一直观的承载力概念，但**彻底剔除手游/魂游式的强化养成、品阶抽卡或复杂属性面板**，直接扎根于原版自带却长期被浪费的 **「材质附魔亲和度（Enchantability）」** 设定。

- **概念定义**：每件可附魔器物拥有固定的 **器魂槽（`◇`）**，仅用于限制**单件装备最多同时挂载几条融合词条**；未融合的普通原版附魔**不占用**器魂槽。
- **材质天生差异（救活原版金装）**：
  - **常规材质装备**（木 / 石 / 铁 / 锁链 / 钻石 / 下界合金 / 弓 / 弩 / 三叉戟 / 重锤 / 盾 / 钓竿 / 鞘翅）：天生 **`1` 格器魂槽（`◇`）**。
  - **金质装备**（金剑 / 金斧 / 金镐 / 金锹 / 金锄 / 金质四件套）：呼应原版黄金全材质最高附魔亲和度设定，**天生自带 `2` 格器魂槽（`◇◇`）**，无需任何扩槽材料即可直接双核联动！
- **后期唯一扩槽途径（严格封顶 `2` 槽）**：
  - 天生 `1` 槽的非金装备，可在融合台消耗 **`1× 回响碎片 + 1× 紫水晶簇`**（或下界/试炼密室同级探索物）进行一次 **「器魂拓印」**，将上限从 `1` 格扩至 **`2` 格（`◇◇`）**。
  - **全游戏硬上限永远为 `2` 格**（金装不可再扩第 3 格）。最多 2 条融合词条即可让每把武器既有深度的双核 Build 配合，又永远不会变成满屏词条的页游神装。

## 5. 第二层：万物跨界自适应矩阵（8 大触发器 × 14 种效果核）

为了兑现 **「副词条全开放万物跨界、任意两本都能合、绝无空转废词条」** 的承诺，同时把开发与维护成本控制在极干净的范围内，所有未被第 4 节手工特调覆盖的组合，均通过数据包驱动的 **「主触发器 × 副效果核」** 二维语法自动合成：

$$\text{融合词条 } [A(x) \rhd B(y)] = A\text{ 的原版效果}(x) \;+\; \Big(\text{Trigger}(A) \xrightarrow{\text{宿主形态适配}} \text{Payload}(B, y/B_{\max})\Big)$$

### 5.1 八大主词条触发器（由主槽 `A` 决定「何时触发」）

1. **`ON_MELEE_STRIKE`（近战重击/连击）**：锋利、亡灵杀手、节肢克星、火焰附加、击退、破甲、致密 —— *跳劈暴击或每第 3 次有效命中触发（内置 `1.5s` 冷却）*。
2. **`ON_SWEEP_OR_CLEAVE`（范围横扫/风爆）**：横扫之刃、风爆 —— *触发范围攻击动作时同步释放*。
3. **`ON_PROJECTILE_IMPACT`（弹射命中）**：力量、冲击、火矢、无限、多重射击、穿透、快速装填 —— *满蓄力箭/弩箭命中生物或方块时在落点触发*。
4. **`ON_TRIDENT_CHANNEL`（投戟/突进）**：忠诚、激流、引雷、穿刺 —— *三叉戟投掷命中或突进撞击时触发*。
5. **`ON_BLOCK_HARVEST`（高效采掘）**：效率、精准采集、时运 —— *连续挖掘方块（每挖掘 `N` 块或破坏矿石/原木时）触发*。
6. **`ON_DAMAGE_TAKEN`（受击/护体）**：四大保护、荆棘、灵魂疾行、迅捷潜行 —— *穿戴者承受有效伤害且满足内置冷却（`3s`）时触发*。
7. **`ON_MOVEMENT_OR_LAND`（踏步/着陆）**：摔落缓冲、深海探索者、冰霜行者、水下呼吸、水下速掘 —— *高处着陆、入水瞬间或疾跑每数秒脉冲触发*。
8. **`ON_UTILITY_CYCLE`（击杀/修补/垂钓/耐久损耗）**：抢夺、经验修补、耐久、海之眷顾、饵钓 —— *击杀目标、拾取经验、成功收竿或触发耐久免损判定时触发*。

2. **绝不吞装备，但死死焊牢**：失稳时**不会炸毁装备或吞空附魔**，而是歪成一条紫红色的 **【畸融异变词条】（`#enchantment_fusion:aberrant`）**。

   - **同时安装《纂刻附魔台》时**：**唯有《纂刻附魔台》「去除附魔」页的高阶【破除诅咒】仪式**，能够斩断排斥死结、将畸融异变词条彻底洗净！

```text
└─────────────────────────────────┴─────────────────────────────────┘
```

- **点睛交互 `[⇄]` 一键正反调序按钮**：玩家放入两本附魔书后，点一下中间的 `[⇄]` 按钮，主副两格瞬间对调，右侧预览立刻从 `A ▷ B` 切换为 `B ▷ A`——所见即所得地对比两种截然不同的流派！
- **常规可逆操作（仅限非异变词条）**：
  - **调序翻转**：把已带 `[A ▷ B]` 的融合书或装备放回融合台，消耗少量青金石/紫水晶与 `2` 级经验即可无损翻转为 `[B ▷ A]`；
  - **拆解还原**：常规融合词条可在融合台消耗紫水晶碎片拆回原本的两本单附魔书（**唯独「畸融异变词条」锁死，提示「排斥死结已深入器物，唯有纂刻破咒之术可解」**）。

### 7.3 融合图鉴（探索驱动与收集爽感）

- **未知迷雾线索**：对于玩家尚未合出过的组合，预览面板不会干巴巴写 `???`，而是显示一句提示机制方向的**工匠批注线索**（例如 `[无限 ▷ 经验修补]` 未解锁前提示：*「若无尽之弦不再贪恋散落的经验，或许唯有命中强敌的战意方能修补裂痕……」*）。
- **永久点亮三页签图鉴**：首次合出任意组合后，永久点亮其在 **【手工王牌篇 / 跨界矩阵篇 / 畸融异变隐藏篇】** 中的图鉴卡，支持按装备部位或附魔名一键检索，并完整接入 **JEI / REI**。

## 9. Minecraft 26.1.2 技术实现架构与开发分期

### 9.1 数据组件（DataComponent）架构 — 零侵入原版附魔表

在 Minecraft `26.1.2` 中，**不要把 1700 种融合组合硬注册成 1700 个原版 `Enchantment` 注册表条目**（否则创造模式物品栏、村民交易池和战利品随机池会被彻底污染！）。最干净的现代架构是：

1. **保留主附魔在原版 `DataComponents.ENCHANTMENTS` 中**（这样原版的锋利面板、效率挖掘速度、保护减伤、附魔紫光、甚至其他模组对主附魔的检测 **100% 原生生效**！）；
2. **新增两个轻量自定义组件**：
   - `enchantment_fusion:fused_pairs`（列表组件，最多 `2` 条）：
     ```json
     [
       {
         "primary": "minecraft:sharpness",
         "primary_level": 5,
         "secondary": "minecraft:channeling",
         "secondary_level": 1,
         "mode": "SYNERGY_OR_MATRIX",
         "aberration_id": null
       }
     ]
     ```
   - `enchantment_fusion:vessel_bonus`（整型 `0` 或 `1`，标记非金装备是否已拓印第 2 格器魂槽）。
3. **工具提示（Tooltip）渲染钩子**：拦截物品附魔行渲染，将原版单调的 `锋利 V` 自动替换为精致的复合显示行：
   - 王牌融合：`◆ 【惊雷斩】 (锋利 V ▷ 引雷 I)`
   - 通用跨界：`◆ [效率 IV ▷ 激流 II] · 破岩引潮`
   - 畸融异变：`☠ 【嗜血无尽弦】 (畸融 · 不可常规抹除)`

### 9.2 全数据包 JSON 驱动目录规划

```text
data/enchantment_fusion/
├── enchantment_fusion/
│   ├── signature_fusions/      # 第一层：手工王牌融合定义（含正反双向 ID、是否需满级、排斥率、参数）
│   ├── aberrations/            # 畸融异变池定义（权重、正负效果参数、整活标记）
│   ├── matrix_profiles.json    # 第二层：每个附魔对应的 Trigger 类别与 Payload 类别及缩放系数
│   └── vessel_rules.json       # 材质默认器魂槽数（金=2，其余=1）、全局封顶(=2)与拓印材料配置
└── tags/enchantment/
    ├── repulsive_pairs/        # 互斥死敌组标签
    ├── triggers/               # 8 大触发器标签（第三方模组挂标签即兼容）
    └── payloads/               # 14 种效果核标签
```

### 9.3 推荐三阶段开发路线图（Roadmap）

- **Phase 1 — 骨架与通用跨界跑通（MVP 可玩版）**
