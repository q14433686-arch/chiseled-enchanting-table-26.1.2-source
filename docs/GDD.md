# 《融合附魔》(Enchantment Fusion) — 完整玩法与系统设计定稿 (GDD v5.0 · 0.5.0)

> **项目定位**：面向 **Minecraft `26.1.2`（Fabric · Java 25）** 的独立原创「原版附魔+」模组  
> **当前版本**：`0.5.0`（Mod ID：`enchantment_fusion`，仅依赖 `fabric-api`，与 **《纂刻附魔台》(Chiseled Enchanting Table)** 支持零硬依赖原生双向祛魔/净化深度联动）  
> **一句话核心卖点**：不破等级上限、不堆膨胀白字——兼具 **「先附为体、后融为用（`[A ▷ B] ≠ [B ▷ A]`）」** 的 **150 条全有向签名共鸣 + 催化×法则双阶矩阵引擎** 与 **「异位化形（140 项全装备跨界单附魔变体 · 3D 实体飞剑掷斧 · `0◇` 器魂槽 · 零污染原版属性）」**，完整覆盖 `26.1.2` 全部 **43 种原版附魔**（含长矛专属新附魔 `突进 Lunge`）、**鞘翅与钓竿全跨界矩阵**、**《纂刻附魔台》原生畸变净化与融合词条析出/抹除**、**4 槽星轨悬浮与像素微粒子动效** 及 **三阶探索《融合秘典》**。

## 核心特性总览（`0.4.1` 实装基线）

1. **100% 正反异构 · 150 条手工「签名共鸣」（`Signature Resonance`）**
   - 覆盖 `26.1.2` 全部 **43 种原版附魔**（含 `突进 I–III` 与全系木/石/铜/铁/金/钻/下界合金长矛），彻底消除对称别名：**每一组 `[A ▷ B]` 与 `[B ▷ A]` 均拥有独立词条名号与截然不同的实战机制**（`147` 条精确双词条配方 + `3` 条副位通配规则 `[X ▷ 饵钓 / 绑定诅咒 / 消失诅咒]`）。
   - 全身 6 槽同名签名共鸣采用**最高等级唯一生效制**（不重复叠加刷屏），保证构筑多样性与数值克制：
     - **`[火焰附加 ▷ 冰霜行者]`「蒸汽灼伤」**：高温高压蒸汽团爆发**无视护甲的真实伤害**（遵守无敌穿透规则）；
     - **`[冰霜行者 ▷ 火焰附加]`「冰火囚笼」**：施加**迟缓 + 灼烧**，并有概率凝结 **`3×3×3` 原版冰霜行者【霜冰】（`minecraft:frosted_ice`）** 临时封困，随时间逐级龟裂消融（支持区块卸载保留与停服清理，绝不永久破坏地形）；
     - **`[时运 ▷ 保护]`「招财金身」**：受非穿透伤害时有概率完全免疫本次伤害（内置 **5 秒冷却**），并以真实耐久结算承受 **双倍护甲耐久损耗**（耐久耗尽会正常碎裂）。
2. **零污染原版属性 · 115 项「异位化形」（`Cross-Domain Transmutation` · `0◇` 器魂槽）**
   - 原版铁砧保持原版准入规则不变以防误敲；在 **`附魔融合台` 页签 ② `器魂铭刻`** 开启 **`[✦ 仅单附魔]`**（或在词条列表按住 **`Shift + 左键`**）即可将单本跨界附魔书铭刻至非原生装备或特殊载体（`不死图腾`、`玻璃瓶`、各类投掷物与消耗品），占用 **`0` 枚 `◇` 器魂槽**。
   - **独立组件隔离（`API-01`）**：跨界单附魔与非本位融合主词条均独立存储于 `enchantment_fusion:transmuted_enchants`，**绝不写入原版 `DataComponents.ENCHANTMENTS` 误触非本位属性**，同时自动同步附魔流光并在 Tooltip 直接展示化形名号（按住 `[Shift]` 展开原附魔来源与机制详情）：
     - **`火焰附加 / 火矢` → 镐/锹「自动熔炼」 & 斧「炭火熔伐」**：后置掉落物转化（完美兼容领地/冒险模式保护、原版时运与统计数据）；「炭火熔伐」按等级将原木煅烧为木炭（I 级 `60%`、II 级 `100%`），**按住潜行（`Sneak`）可随时暂停熔炼直接采集原木**！
     - **`水下速掘` → 刀剑/长矛/弓弩/重锤「沂水」**：身处水中或雨中时增加 **`+1.5` 攻击距离**并提升水战伤害。
     - **`灵魂疾行 / 荆棘 / 时运 / 突进` 跨界**：近战 **「追魂步」** + 非靴护甲 **「幽魂脱兔」** + 弓弩 **「引魂矢」**；近战 **「锯刃」**（流血 + **不分青红皂白将苦力怕等一切受击怪物拽向自身**）+ **「倒钩矢 / 刺盾」**；非工具 **「三美金 ($3 Bill)」** 随机元素轮盘；非长矛 **「寸步突刺 / 跃射步 / 疾行突步 / 掘进冲刺」**。
     - **特殊无耐久载体**：`不死图腾` 上 `耐久` 化为 **「裂而不碎」**（非 `/kill` 致命伤下 `10% / 18% / 25%` 救命不碎）；消耗品与投掷物经服务端实耗校验后触发 **「经久省用」**（杜绝冷却期刷珍珠/烟花漏洞）；空 `玻璃瓶` 上 `经验修补` 化为 **「凝灵成瓶」** 吸取经验凝结 `附魔之瓶`。
3. **精炼双页签工作站（`308×214`）+ 双页《融合秘典》（`360×224`）+ 三阶探索**

| **低阶合成** | 总等级 `< 4` | `2× 青金石` + 基础经验 | **`0%`（100% 必成）** | 新手零挫败，自动消耗 **`0` 枚** 共鸣稳定晶。 |

### 6 种实装「畸变词条」（`Aberrant Fusion` · 唯《纂刻附魔台》可净化）

原版砂轮（保留洗除普通附魔，但死锁保留畸变词条并清理孤儿组件）、原版铁砧与附魔融合台均无法拆解畸变词条；唯有安装姊妹模组 **《纂刻附魔台》(Chiseled Enchanting Table)** 时，可通过其祛魔净化仪式剥离：

1. **`ab_blood_frenzy`「狂血反噬」**：近战/远程命中爆发额外凶戾伤害，但每次触发反噬自身微幅生命。
2. **`ab_rogue_lightning`「走火雷劫」**：攻击高频引落狂暴雷电轰击敌群，但偶有偏折电弧劈中持有者自身。
3. **`ab_greedy_abyss`「贪婪黑洞」**：采掘矿石有概率翻倍爆出珍稀矿物，但挖掘普通岩石时有概率被黑洞吞噬化为虚无且加速磨损。
4. **`ab_recoil_skid`「反向滑铲」**：射击或挥击附带强劲冲量爆发，但巨大后坐力会将使用者自身向后震退滑行。
5. **`ab_mutual_glacier`「敌我同冰」**：受击或命中时在原地凝结 `3×3×3` 霜冰囚笼封冻周围一切生物（连同穿戴者自己一并关进冰笼）。
6. **`ab_hot_potato`「烫手山芋」**：赋予狂热攻防爆发，但器物周期性发烫灼烧持有者并伴随惊呼音效。

## 数据组件与网络同步架构（Minecraft `26.1.2`）

### 四项核心数据组件（`FusionDataComponents`）
- `enchantment_fusion:fused_pairs`（`FusedEnchantmentList`）：承载至多 `2` 条有向融合词条 `[A(x) ▷ B(y)]`（构造器与 Codec 双重等级截断校验）。仅当主词条 `A` 原生适配当前宿主装备时才同步至原版 `DataComponents.ENCHANTMENTS`。
- `enchantment_fusion:transmuted_enchants`（`Map<String, Integer>`，上限 `16` 条）：承载 `0◇` 异位化形单附魔与非本位主词条，彻底隔离原版非本位属性泄露。
- `enchantment_fusion:vessel_bonus`（`Integer`，截断至 `0..1`）：记录非金装备是否已完成 `+1◇` 器魂拓印。
- `enchantment_fusion:page_tier`（`Integer`，截断至 `0..2`）：标识普通 / 古旧 / 畸变三阶《融合残页》。

### 数据包目录与网络协议
- `data/enchantment_fusion/enchantment_fusion/matrix_profiles.json`：`43` 项原版附魔的 `Trigger × Payload` 映射（支持 `"replace": true` 覆盖模式，未显式配置的第三方附魔基于原版 `Enchantment` 槽位与标签自动推断）。
- `data/enchantment_fusion/enchantment_fusion/repulsive_pairs.json`：原版互斥附魔组定义（含 `锋利×亡灵×节肢`、`四大保护`、`无限×修补`、`时运×精准`、`多重×穿透`、`忠诚×激流`、`引雷×激流`、`深海×冰霜`、`致密×破甲`，支持 `"replace": true` 与空列表清空）。
- `data/enchantment_fusion/enchantment_fusion/economy.json`：阶梯经验、材料消耗、基础失稳率、稳定晶单枚减免与互斥保底下限配置。
- **网络协议（`FusionNetworking`）**：`StationActionPayload`（固定协议号 `10..17` + 服务端速率守卫 + `sourceSlot|enchantId` 令牌防竞态）、`MatrixSyncPayload`（进服与 `/reload` 同步矩阵及经济配置）、`CompendiumSyncPayload` + `CompendiumDeltaPayload`（全量上限与单条增量图鉴同步）。
