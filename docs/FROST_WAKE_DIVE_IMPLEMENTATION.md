# 冰霜行者 × 深海探索者：保留玩法及边界

> 本页描述已写入的方向载体、目标筛选与旧路径选择；相关代码已通过云端编译及 JUnit（44/44），游戏验收尚未进行。第 22 组的冰路、潜泳核心不重设计。最终须在一次游戏进程中逐项记录通过、失败或跳过及原因。

## 两方向与实际对象

新装载到**靴子**，实际穿在脚部才触发。融合书、直接融合、升级和翻转均使用同一检查；不按原版附魔载体交集推断，也不缩小单附魔跨种。两个附魔互斥，既有满级融合/不稳定规则不变。

**冰霜行者 ▷ 深海探索者｜玄冰凝海**：未潜行、未浸水时，继续尝试在源水上方空气铺设临时薄冰路，灭火并寒冷附近目标。逐格验证原版权限、世界边界、已加载区块和活体碰撞，不替换原水、植物或其他方块；薄冰打碎/老化后为空气。为了避免把玩家、宠物、村民和无关中立生物冻住，穿戴靴子的新路径只处理合法敌对目标、正在攻击玩家的中立生物和服务器允许的非盟友 PvP 玩家；保留之前落地时的通用潮汐加成。原版主位霜行的行走伤害免疫保留，冲突的冻水写入由原水保护拦截替代，细节见[霜势实现](FROST_FALL_IMPLEMENTATION.md)。

**深海探索者 ▷ 冰霜行者｜破浪潜行**：潜行时只移除脚下本模组的临时薄冰，不将其变成水、不更改任何原版冰；在水中潜行时沿视线向前推进。保留原版主位深海探索者和既有落地霜冻/临时水面薄冰加成；新版靴子的落地范围霜冻同样使用上述合法目标过滤。

两方向都仅在默认对应签名仍生效时套用上述限制。旧不适用装备不强制改写或删除，原有手持/穿戴行为继续走旧路径并提示旧载体，原版附魔不被批量修改。穿戴新版靴子与手持旧载体同时存在时，优先执行实际穿戴靴子的相同方向；仅手持靴子不触发新版。旧不适用载体保留旧目标筛选与旧原版附魔行为，可能仍会影响非盟友或冻水，不能误称已被迁移；玩家可自行在安全条件下处理。

## 验收与限制

`FrostWakeDiveProbe` 已准备两个方向的融合书/直接融合载体验证、手持靴子不触发、旧载体回退及穿戴优先级探针，但尚未运行。还需在最终进程中测试正常游泳、浅水/深水与潜行切换、薄冰寿命/破坏与其他方块、多人游泳、世界边界/出生点及第三方领地、敌我和 PvP、原版冻水及岩浆伤害免疫、原版深海探索者与其他速度加成叠加、旧装备、复数装备和数据包热重载。冻伤是状态修改，未经过伤害事件，领地或状态保护模组能否拦截不能仅凭原版 `mayInteract` 保证。异常副作用和其他附魔自定义位置效果也须分别验证。
