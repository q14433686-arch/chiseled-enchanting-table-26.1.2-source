# 47–52 批：同载体替代动作与兼容修订

> 这是助手对既有**未逐项确认的草案**作出的透明修订，不改变用户已选专属、通配、保留项或已选模板。本页只给下表中明确列出的方向增加“不强迫玩家先换成另一件特定装备”的动作；原文仍保留为历史及可选的跨装备玩法。若玩家主动使用原方案的真实弓、工具、三叉戟或钓竿，真实资源和事件仍需照常成立；同一份势二选一消耗，不能靠两种动作领两次。
>
> 例如用户已选的 **44.4 水战作业**和 **46.3 命中备掘／掘后引矢**明确包含真实工具或真实箭；本页不改写这些已选模板及 50.14、51.07 中对它们的展开。效率 × 多重射击继续按用户选择保留现状。不要为了消除换装备而把已选真实操作悄悄改成虚影。

## 实施共约

- 同载体动作兑现时来源装备必须由本人实际持握或穿戴；状态绑定玩家、来源物品实例和有序融合，不属于其他装备，并显示可见提示。可选的原跨装备分支在来源装备仍归本人所有时允许暂存，再用另一件真实装备兑现；没有合法目标或真实动作就不消耗，虚拟状态超时不扣真实资源。跨装备分支仍需实际动作、权限、弹药、工具和耐久，不创造或传送真实装备。
- 虚拟水枪、火矢和水压不是真实三叉戟、箭、水、火或可拾取物。手动释放需玩家主动瞄准，遇实体方块停止；自动目标只选合格敌对生物或正在攻击本人的中立生物，保护玩家、盟友、驯服生物和村民，合法主动 PvP 与服务器规则另行测试。可选真实投射物仍按其原有规则和权限处理。
- 先发生原提案要求的**真实**主位事件才获得一次势，不能使用虚影重新触发本项，持续时间、距离、威力与冷却仍按实现测试调整。未在本表列出的方向维持原草案，不把这些补充泛化为对所有方向的替代。

### 穿戴装备与投枪主题

这些原方向允许防具穿戴的同时手持三叉戟，不一定需要脱换来源装备；但如果玩家没有三叉戟，原草案仍没有可执行的副位动作。以下补上主动虚拟动作，并保留实际投枪分支作为选择。所有额外攻击不得仅因正常受击、行走或呼吸而自动发出。

| 编号 / 有序方向 | 不依赖另一件真实三叉戟的选择 |
| :--- | :--- |
| 47.24 保护 ▷ 穿刺 | 真实减伤积护流后，玩家瞄准主动放出水刺并围绕本人形成短暂护幕；只对合格水生目标造成刺击。 |
| 47.25 火焰保护 ▷ 穿刺 | 真实抵御火焰积余热后，主动向合格水生目标放出一次虚拟蒸汽枪；不产生火或水。 |
| 47.26 爆炸保护 ▷ 穿刺 | 真实承受或减免爆炸积震压后，主动释放一次对合格水生目标生效的穿透水压；不产生真实爆炸，不改变第 16 组例外。 |
| 47.29 灵魂疾行 ▷ 穿刺 | 魂沙土上真实移动积魂路后，玩家主动沿选定的魂路方向放出虚拟潮刺，作用于沿途合格水生目标。 |
| 47.30 迅捷潜行 ▷ 穿刺 | 真实潜行移动积潜势后，玩家主动瞄准释放一次定向水刺；不要求敌人绕背。 |
| 47.31 摔落保护 ▷ 穿刺 | 真实合格落地或入水积落势后，玩家主动瞄准释放一次水压枪；不伪造落差。 |
| 47.32 深海探索者 ▷ 穿刺 | 水中连续真实移动积泳势后，玩家主动沿选定方向释放虚拟长水枪；遇实体方块停止。 |
| 47.33 冰霜行者 ▷ 穿刺 | 踩过合格冰面或模组临时薄冰积霜路后，玩家主动瞄准释放虚拟冰枪；保留原水，临时薄冰消失不产水。 |
| 47.34 水下呼吸 ▷ 穿刺 | 水下确认合法目标及可用氧气后，玩家可主动瞄准释放一次压缩水刺，实际释放时扣氧；无目标或氧气不足不支付、不扣生命。原下一次真实投枪分支仍可选，支付一次只能选一个。 |
| 47.37 经验修补 ▷ 穿刺 | 本装备被本人真实经验修复后积锻枪痕；玩家主动向合格水生目标释放一次虚拟水刺。来源装备若本来可真实投枪，也可继续选择原分支，不复制经验。 |

| 48.22 饵钓 ▷ 时运 | 真实钓获后，可把白名单内一份真实普通渔获投入可见的浮标押注：按一次可配置概率，赢则获得两份同种普通渔获（净增一份），输则损失投入物。投入前明确显示风险、先真实扣除，再按一次结果结算，有冷却和产量限制，容器、自定义数据物品及不可合法结算物品排除。原用真实工具采矿的矿运分支仍可选，同一份渔获只能用于其中一种；这不是 39.4 的渔获品质选择。 |

这些是可实现方向的**设计修订**，不是现有游戏功能；原版附魔衔接、事件 API、目标筛选、数据迁移、平衡及实际手感需集中实现和测试。
