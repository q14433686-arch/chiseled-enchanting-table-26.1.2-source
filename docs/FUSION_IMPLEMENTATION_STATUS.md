## 准备的游戏探针与本轮结果

- 已在现有客户端 smoke 中准备潜游保水/原版冰/权限、火焰主位碎釉、第三方分类、补给经验、掉落物危险来源以及采掘产物归属的部分服务端探针；本轮**尚未运行游戏进程**。这些探针中有手动调度服务端事件的部分，不能声称等同于真实鼠标操作或双客户端联机。
- 用户要求的是全部实现后，在**一次游戏进程内逐项**记录通过、失败、跳过及原因。目前还没有该验收结果。静态检查、Java 编译和 JUnit 不算游戏实测；自动 smoke 也不自动等于完整逐项验收。
- 需要继续实现：其余方向的专属/通配/模板优先、实际对象、状态及资源归属、原版效果衔接、第三方分类与跨种；随后才能构建完整的单进程逐项测试与结果表。
