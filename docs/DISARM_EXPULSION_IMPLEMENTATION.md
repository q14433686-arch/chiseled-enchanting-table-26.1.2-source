# 第 08 组：抢夺主位的缴械驱逐（候选）

仅覆盖选中签名 `trophy_shockwave` 的 **抢夺 ▷ 击退**，不影响数据包将同一对映射到其他签名；不适用的旧载体保留旧数据、旧技能和旧提示。方向载体为实际可近战的剑、斧、长矛、重锤和三叉戟，两种融合入口采用同一校验。另一方向见[截势追击](PURSUIT_PLUNDER_IMPLEMENTATION.md)。

## 动作和真实物品

- 满蓄的直接近战必须经过许可，真实损失生命或吸收，且完整攻击正常结束；异常、重入和多次不明归因跳过。命中后只选择仍活着、双方可合法攻击、未超出距离的**原版普通敌对或实际敌对中立生物**；不对玩家、村民、队友、驯服或其他受保护对象生效。末影龙、凋灵、监守者、远古守卫者、大于 100 最大生命的实体和 `enchantment_fusion:disarm_immune` 实体类型标签中的对象不能缴械。第三方实体类型暂时保守跳过，不猜测它们的首领、背包及归属语义。
- 以主手、副手、头、胸、腿、脚顺序选择一件实际装备；空槽、非装备、堆叠数量不是一、原版绑定、融合／跨种或保留条目中带绑定的物品跳过。每个目标 100 tick 最多一次，限制短时整套剥离；不会扣掉耐久或复制装备。目标位置仍须通过原版 `mayInteract`，不等于第三方领地或物品所有权许可。
- 保留目标真实 `ItemStack` 的对象身份与组件：先在原地注册同一物品引用的暂不可拾取实体，再复核装备、物品和世界身份，才清空同一个实际槽位；注册被拒绝或物品／槽位提前改变时不清空装备。正常完成后恢复普通拾取延迟，将物品朝玩家方向轻推并按目标抗击退将敌人朝反方向推开。玩家仍需正常拾取，不自动进入背包；不生成赎金、经验球、额外物品或虚拟伤害。
- 交易有重入防护和失败清理：同一次回调中禁止重复缴械；若原物仍在目标其他槽位则撤销物品实体，若物品实体是唯一已知原对象则保留而不丢弃。仅通过身份而非等值物来做归因，不将快照作为产物生成。第三方在注册或装备回调中自行复制、移动、拾取物品，或存档恰在实体与装备分别持久化之间断电，仍无法获得跨模组／跨存档原子保证，须游戏及兼容复核；这些情况下不能承诺绝不丢失或重复。
- 抢夺主位保留。原生附魔正常参与战利品；缺失原生投影的实际主手载体复用 40.1 的同次真实死亡战利品和装备掉率观察，将缺失的抢夺等级用于对应查询，不永久修改武器或重复叠加原生等级。缴械不会标记 40.1 的钩索掉落，也不拿走附近其他物品。
