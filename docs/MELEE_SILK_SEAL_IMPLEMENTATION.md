# 精准主位的近战封伤：候选实现与边界

覆盖 33.4 的 `精准采集 ▷ 锋利` 专属反向，以及 44.1 中 `精准采集 ▷ 亡灵杀手 / 节肢杀手` 两个模板反向。**攻击附魔主位的截弹、反发仍未实现**，不能把这三条反向当作整个 33.4／44.1 完成。剑、斧、长矛、重锤为新载体；不适用的旧载体不改数据，保留旧效果。其他数据包自定义专属优先；原 `pristine_trophy` 是已选锋利反向例外，在适用新载体上不再额外触发旧的击杀头颅奖励。工作台两入口使用同一载体验证；技能键、装备提示、预览和图鉴说明对应新能力。

- 主手按技能键后有 8 秒准备时间。满蓄命中可选合法目标时，保存本次伤害，目标减速 30% 最多 6 秒。同一物品实例再次命中同一目标，在那一次真实攻击中合并释放；再次按技能键主动消散。到期、目标卸载或死亡、双方不再合法、持物更换、玩家死亡、掉线或换维度均消散并清除自有临时减速。每人最多一个状态，每个目标最多被一人封存；不生成独立实体或额外物品。
- 不向权限监听器伪造零伤害。候选代码在玩家真实伤害调用期间设立作用域；原始正伤害先经过服务端伤害许可、无敌与格挡检查，之后仅在 `LivingEntity.hurtServer` 调用 `actuallyHurt` 时暂缓其传入金额。禁伤、不可攻击、阻挡、非满蓄、无合法目标或作用域身份不匹配时不封存。只有真实外层返回成功且确认没有生命／吸收损失时才创建状态；截获之前发生嵌套攻击时保守退回普通攻击。截获之后对其他目标的可辨认嵌套攻击不会自动抛弃封存；若同目标或无法辨认的嵌套、其他模组改写或异常使结算发生歧义，当前实现不会认领封存、也不会补造绕过权限的伤害，这次攻击可能损失，必须继续验证和改进。减速使用本模组独有的临时属性 ID；登记目标归属后才写入，清理时同时核对目标状态所有权与属性值，旧状态不得清掉后续状态的减速。
- 被封存的金额是首次攻击通过伤害许可和无敌时序后、护甲／附魔减伤前的金额。释放加入下一次真实伤害请求，经过当时的权限、盾牌、护甲和附魔保护；不会重新播放首次攻击的附魔伤害计算。被权限取消且未发生格挡的释放保留状态；真实进入结算或盾牌已消耗时即消费，防止反复损耗盾牌或重复释放。溢出钳为有限数值。
- 原版外层仍把封存命中视作已接受攻击：动画、击退、攻击侧物品使用等普通命中流程可能发生。本模组自己的 `AFTER_DAMAGE` 健康触发路径在确认零损失的封存调用中跳过；**其他模组的 Fabric `AFTER_DAMAGE` 仍可能收到原始正伤害**，不能宣称所有第三方健康监听器已兼容。其他 Mixin、嵌套回调或异常在封存边界之后改变结算时，也必须实测；无法安全认领就不创建状态，不补造绕过权限的伤害。
- 首次伤害在捕获时不执行原护甲耐久，释放时以合并后的真实伤害结算；目标中途换装或防护变化以释放时为准。原生精准采集如果在载体上真实存在，正常采掘效果不被移除；此实现没有伪造方块掉落。
