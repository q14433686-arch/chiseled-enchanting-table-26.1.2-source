# 精准采集 ▷ 火焰附加：琥珀焰封

> 这页记录新方向的代码和待验收边界，不是游戏验收报告。须等全部重设计写完，在同一个游戏进程里逐项记录通过、失败、跳过及原因。

## 对象、输入与原有效果

新融合的载体是**剑、斧、长矛、重锤**；实际在**主手**时使用。融合书装入、两书直接融合、升级与翻转沿用同一方向载体检查，不取两附魔原版适用装备的交集。其他旧载体的融合数据不迁移或删除，仍走旧迟缓/魂火和击杀范围效果，物品提示将其标为旧载体；数据包把该附魔对映射为别的签名时，不强行套用本实现。多能力混合物品只要具有任一上述武器载体分类就可使用，不因单一跨种角色优先级丢失其武器能力；单附魔跨种规则不变。

用可重绑定的主动技能键（默认 G）封火，多个可用主动技能用切换键（默认 V）选择。客户端只发送无目标、无数值的请求；服务端检查主手装备、打开的菜单、状态、冷却和朝向，并对前方六格做方块与实体射线，不穿墙或穿过可选中的前方实体。成功后再按同一技能键可提前撤销；失败不消耗冷却。

为了使该方向能够独立形成操作循环，**持该武器的真实非格挡命中会先点燃目标**，火焰时长为 `4 秒 × 火焰附加副位等级`（计算上限 10 级）；玩家也可先用其他来源点燃再封。这里是该专属能力明确提供的点火，而不是把副位强行写入原版附魔组件；使用原版 `igniteForSeconds` 的“取较长时间”语义，若另有独立原版火焰附加，不把两个计时相加。顺序上本技能点火发生在本次伤害确认后、原版攻击后置附魔效果前；修改原版火焰附加的数据包或其他模组对后置效果顺序的假设仍需兼容测试。

精准采集是主位：仍按既有正常规则保留在可以原生附着它的装备上，例如斧子；剑等原版不支持时不强塞原版附魔，融合数据仍保留。火焰是副位，不额外投影为一份原版附魔。新版武器不再触发旧琥珀的额外魂火、魔法伤害、击杀爆散和概率蜜脾，也不叠加通用矩阵收益；旧的不适用载体保留原先效果。

## 封存、再击与安全结算

对准合格的**已有燃烧**目标主动使用，读取并清除当时的原版剩余燃烧计时，生成一个仅在服务端内存中存在的虚拟封印，不放实体方块。目标获得独立、可同步的临时移动速度乘数 `×0.60`；不删除或改写已有药水状态。封印后其他来源重新点燃目标不会被反复熄掉，撤销时也不会缩短那份新火。每人最多一个封印，每目标最多一个，封印与待释放冲击全服合计最多 256；成功激活冷却 60 tick，封存持续 `80 + 20 × 精准采集等级` tick（计算等级限制 1–5）。属性 ID 已被占用、目标已被封、资源满额或没有合格目标时不会扣火。

拥有者再次以**同一件主手武器**真实命中该目标时，消耗封存的火并排队释放一次热晶冲击：直接目标伤害 `2.4 + 0.6 × 精准等级 + 0.7 × 火焰等级 + min(4, 封存火焰 tick / 100)`，等级计算限制 1–10；随后半径 `1.6 + 0.2 × 精准等级`（计算等级限制 1–5）内至多 16 个合格其他目标各受一半伤害，碰墙不穿透；至多收集 128 个合格候选并在其中按距离排序，极端拥挤时不保证选到全场最近目标。使用归属攻击者的魔法伤害，原版护甲不减免，其他伤害事件、药水、PvP 和图腾仍有机会生效。直接目标的本次追加伤害临时绕过本次攻击产生的无敌帧并恢复原值；范围内其他目标保留正常无敌帧。冲击不放火方块，不直接改地形。

输入射线是玩家主动选中的目标：允许非盟友、非无敌的生物，也允许服务器及队伍规则允许的玩家；因此玩家主动瞄准的非敌对动物或村民也可能被减速/攻击。**自动波及**则更保守：保护村民、驯服生物、盟友、无敌者，以及未在攻击玩家的中立生物，只考虑敌对生物、正在攻击玩家的生物及合法 PvP 玩家。各目标额外检查原版 `mayInteract`；这不能保证第三方领地或状态保护插件一定拦截本技能。

取消、到期、换件或修改融合、目标或拥有者换维/卸载/断线、目标变为无效、数据包改签名，以及正常关服时会移除本技能自己的临时减速。目标仍存活且干燥、不在岩浆且不免火时，归还 `max(0, 原封存火焰 tick − 已经过 tick)`，只延长不缩短后来产生的其他火；入水、淋雨、进入岩浆时封印消散，不强行恢复被环境熄掉的火。目标因其他原因死亡不会触发冲击。正常卸载事件和关服回调会尽量在保存前恢复；异常崩溃、第三方先行序列化及不使用原版火焰计时的效果不能保证恢复。

## 命中确认、异常与待验收

`PlayerAmberAttackMixin` 仅包装原版 `Player.attack` 与 `Player.stabAttack` 内实际的 `hurtOrSimulate` 调用，记录这次伤害来源、目标和使用的具体武器。普通非致死命中由 Fabric `AFTER_DAMAGE` 确认；致死命中单独使用 `AFTER_DEATH`（`AFTER_DAMAGE` 不报告致死）；被取消、完全盾挡、0 伤害和只造成击退的刺击不消耗封印；非致死回调报告有盾挡时也不消耗。`AFTER_DEATH` 不携带盾挡标记，因此部分格挡但仍致死的伤害可能释放封印，不能声称致死盾挡已被完整区分。致死命中时尸体不再接受直接伤害，但仍能在其位置释放一次小范围冲击。扫击附带击中的其他目标不走直接命中封印确认。图腾救回、模组实体覆写伤害或模组嵌套复用同一来源对象时的事件顺序仍须实测；不声称任意第三方伤害都可准确归因。龙的分段部位可能不等于其活体父实体，目前不能承诺适用于这些部位。

异常融合在确认冲击时沿用近战异常冷却并执行独立异常效果；异常可能召唤雷电、临时冰或影响玩家，普通技能不改地形的说明不涵盖它。数据包更换签名、独立附魔和多人策略、自动存档与区块卸载先后、异常副作用、药水叠加、实体属性冲突均需进一步验证。

已准备 `AmberSealProbe`：载体与工作台预览、服务端射线遮挡、真实 `Player.attack`、取消伤害、换件退款、长矛 `stabAttack` 主副手和致死路径；**尚未运行**，也不等于真实键盘、自然刺击操作、PvP、多人、图腾、区块卸载或第三方保护插件的游戏验收。Mixin 目标和注入顺序必须在最终 26.1.2 游戏进程中验证。
