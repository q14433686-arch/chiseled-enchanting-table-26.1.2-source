### 📖 概述

「纂刻附魔台」（Chiseled Enchanting Table）将原版附魔台的"随机三选一 + 反复 roll"流程替换为
**确定性、依赖资料库**的工作流：

- 新增方块 **纂刻附魔台 (Chiseled Enchanting Table)**；
- 在附魔台周围摆放**纂刻书架 (Chiseled Bookshelf)**，往书架槽位里放入**附魔书**，对应的附魔就被
  **永久解锁**到这张附魔台的可选列表里；
- 打开附魔台界面后，从一份**可滚动的列表**里直接挑选你想要的附魔施加到物品上 —— 无随机性、无
  重 roll；
- 施加一次附魔会**消耗一本对应的附魔书**（这就是要建一个小型附魔书库的原因）以及一点经验和材料，
  消耗量在界面里直接显示；
- 一部分原版附魔（对应 `#minecraft:non_treasure` 标签 + 少量被本模组额外解锁的宝藏附魔）**默认即可选**；
  其它附魔则按原版的方式靠探索/掠夺附魔书来扩展资料库，但**一旦放进书架就永久保留**；
- 附魔台界面里还内置了少量**物品转化配方**（如 金苹果 → 附魔金苹果、玻璃瓶 → 附魔之瓶），用同一
  套消耗 UI；
- 沿用上游设定：你**不再能**通过铁砧把两本同等级附魔书合成更高一级 —— 想升级请走"书架 + 纂刻附魔台"路线。

### 🧰 上手流程

1. **合成纂刻附魔台**（合成配方与原版风格一致，游戏内配方书可查）。
2. 在附魔台周围放置若干**纂刻书架**，搭一个小型书库；普通书架仍然提供基础等级加成。
3. 把**附魔书**塞进纂刻书架的槽位，每本书提供的附魔会出现在附魔台列表里。
4. 打开附魔台，把要附魔的物品放进输入槽，滚动列表挑想要的附魔，按界面显示支付经验 + 材料，
   一本对应的附魔书会被消耗，附魔生效。
5. 当输入槽为空时，列表里会出现**物品转化配方**（如 金苹果 → 附魔金苹果），同样支付经验 + 材料
   即可获得产物。

| 项 | 上游 `0.2.x`（1.21.x） | 本非官方 26.3 移植版 `1.1.0` |
|---|---|---|

| Java | 21 | **25** |

| 经验扣除方式 | 直接扣等级 | 扣经验点（vanilla 铁砧风格，高低等级公平） |

### 🧩 兼容性现状

- **原版 + Fabric API**：全部核心路径**已真机验证通过**——放置方块、打开界面、滚动列表、施加附魔、
  物品转化、附魔书转移、采掘掉落、悬浮书渲染、宝箱附魔书战利品注入、村庄/林地府邸/古城/要塞书房
  的雕纹书架自动生成与装填、经验点扣除（vanilla 铁砧风格）。
- **会把自家附魔挂到 `#minecraft:non_treasure` 标签上的第三方附魔 mod**：设计上**会被自动识别**
  并加入默认可选列表，无需为每个 mod 单独配置。
- **Universal Enchants** 这类改写物品/互斥关系的 mod：无需移植端额外代码即可生效（`Enchantment.canEnchant`
  / `areCompatible` 从活注册表实时读取）。
- **Merge Enchantments** 这类作用于原版铁砧的 mod：与本附魔台是互不干扰的两条交互路径，共存。

详细分析见仓库 `docs/COMPATIBILITY.md`。

### ⚠ 移植版临时限制（已知、非 bug）

以下上游已有但本移植端尚未重新接通的内容（1.0.x 已解开的项已从此列表移除）：

- **铁砧 mixin**（`RemoveEnchantMerge`, `RemoveXpCostScaling`）—— 原版铁砧行为目前未被修改，上游的
  "禁止同级附魔书铁砧合成升级"这条平衡改动尚未在 26.3 上重新验证；
- **附魔书架的环境粒子/音效**（上游 `ChiseledBookshelfTick` 提供的当书架里有附魔书时的悬浮
  附魔粒子）暂未接通；
- **第三方 mod 集成层**（如 Colorful Books 联动）暂未移植；
- **独立多槽位消耗面板**——额外消耗物品目前仍从玩家主背包静默扣除，尚无独立 UI 展示。见
  `NEXT_TASK.md` 中 1.1.0 排期。

请在反馈时一并理解这些是**已知边界**，不是 bug。
