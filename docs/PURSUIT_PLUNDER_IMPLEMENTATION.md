# 第 08 组：击退主位的截势追击（候选）

仅覆盖 **击退 ▷ 抢夺**。反向 **抢夺 ▷ 击退** 的候选实现及真实装备转移边界见[缴械驱逐](DISARM_EXPULSION_IMPLEMENTATION.md)；两方向均未游戏验收。现有旧签名 `concussive_plunder` 在适用的新载体上由此机制接管，不生成物品或战利品；不适用的旧载体不删数据，继续走旧效果。数据包将这一附魔对映射到别的签名时，不抢占该签名。可执行真实近战的剑、斧、长矛、重锤和三叉戟为候选载体；融合书装载、直接融合使用同一方向校验。

## 动作与共用证据

- 首次直接命中必须有实际生命或吸收损失，目标和玩家需处于可合法攻击的状态。仅在这一次真实 `LivingEntity.knockback` 改变目标水平速度之后，才复用 42.5 的动量标记和真实 `Entity.move` 碰撞裁剪轨迹；完全抗拒击退、伤害被取消或仅靠传送、位置校正不能创建／保留可信轨迹。
- 默认标记至多持续 60 tick；须用**同一实际主手物品**再次真实命中同一仍存活、未乘骑或飞行的合法目标。目标最近的实际运动须仍朝首次推出方向，最近一次有效位移不超过 2 tick，途中位置和已观察步骤须连续。玩家本身不能乘骑、飞行或旁观。失去装备、死亡、换维、卸载、轨迹失真等由共享状态清理；每人至多 4 个标记、全服最多 256 个。
- 第二次攻击的真实伤害调用**之前**记录目标剩余速度，不能把这次伤害或附魔产生的新击退当成先前动量。完成整次攻击并处理原版击退、玩家速度包后，只从当时仍同向的水平速度扣除至多那份事先观测的速度，其他方向和垂直速度保留；玩家沿这次实际运动方向获得有上限的水平冲量，目标短暂获得缓慢 I。冲量按实扣速度及等级缩放，最大 1.25 格/tick；无可辨认的剩余动量不生成冲量。正常碰撞和重力仍由游戏处理。
- 只消费一次标记；本次成功追击不会立刻用同次击退重新建标。嵌套攻击、攻击异常及未确认伤害回调却改变目标速度时，旧标记立即失效，避免把新的外部冲量算成旧动量；不扫描或拿走掉落物，不复制资源，也不生成虚拟攻击伤害。PvP 目标仍须通过原版可伤害和双方队伍等目标规则，村民、盟友和受保护驯服生物不作为目标；`mayInteract` 只覆盖原版出生点及边界规则，不能保证第三方领地模组。
- 保留原版击退主位。原生可投影时不重复；非原生的实际主手武器，复用 42.5 对当前数据包击退主位的伤害、击退和攻击后效果重放，并与同次其他击退重放去重。抢夺副位在此方向表达“夺势”，不凭空加掉落；其他独立附魔保留。不同旧载体仍使用旧签名，并在提示中区分。

## 验证与边界

已准备独立 `08-knockback-looting` 候选探针，检查工作台两入口、真实攻击、完全抗击退、伤害取消、取消但速度改变、嵌套及异常帧清理、村民、标记、人工移动、同一物品、消耗一次、静止后新击退、传送和非原生主位；另有匹配优先级与有限数值单元测试。`d44071f` 的 compile-check `41431014240`、build `41431014304`、无 JEI/REI 编译和 JUnit **238/238** 成功；后续审计发现当时完成标记早于其他 frame 清理，已调整为所有本模组内层 frame 正常关闭后才结算，修正仍需重新编译。游戏任务 **SKIP**。探针直接调用服务端攻击，并人工设置运动及标记时间，**尚未在游戏中运行**，不能代表自然输入、网络同步或游戏 PASS。

必须在统一进程中回归已有 42.5 六方向、39.3 和 40.1 的共用击退／移动、有效武器及装备损毁；普通单机模拟不证明真实 PvP 客户端权威移动、多玩家、其他 Mixin、位置修正或第三方实体保护。任何未覆盖场景应单独记 SKIP。图鉴和预览是新方向说明；旧不适用物品工具提示保留旧签名描述。
