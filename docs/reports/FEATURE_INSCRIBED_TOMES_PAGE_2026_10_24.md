# 新功能：「纂刻的书」页 + 功能页解锁 + 模板书锁定（2026-10-24）

基线：`26.3` 分支尖端（PR #21 合并后，含设计审计包）。四项机制决策经维护者选定：
退魔献祭解锁、按玩家成就存解锁、提前解锁仅锁定者（1 级经验+1 退魔砂）、锁定全渠道拦截。

## 玩家可见行为

- **第三个页签「纂刻的书」**（与退魔同皮、琥珀换色）：页眉显示范围内雕纹书架数、
  模板书总数、当前每点充能时长与「距下一阶段还差 X 架 / 已达最高档」；每本书一行：
  附魔与等级、剩余/上限耐久（世代折损后）、「+1 还要 m:ss · 充满 m:ss」实时倒计时
  （服务端每 20 tick 同步进度、客户端本地插值）、锁徽标。点击多选，底部四键：
  锁至 +1 / 锁至充满 / 永锁 / 解锁。
- **功能页解锁（按玩家）**：「退魔洗练」与「纂刻的书」初始上锁（服务端真门控，
  客户端点不动+悬浮提示「未解锁该功能页，请前往纂刻秘典查看详情」）。
  - 纂刻的书：范围内 ≥4 个雕纹书架且各有一本附魔书 → 自动授予成就**「还要多久……」**并解锁。
  - 退魔洗练：把 12 本褪魔残卷放进台范围内的雕纹书架，站在台旁于**秘典第八章**
    点献祭按钮焚尽之 → 成就**「退魔之途」**并解锁；祖父条款：已有
    `cleanse_enchantment` 成就的老玩家自动解锁，老存档不倒退。
  - 服主总开关 `feature_page_locks`（默认开）可整体关闭解锁制。
- **锁定**：免费；锁定中不可取出（含漏斗）、不进入任何附魔/仪式候选；
  限时锁在充能达标的那次再生结算自动解除（充满后残留的限时锁读作已过期）；
  书架被拆时锁跟书走（NBT 在书上）；提前解锁仅锁定者，每本 1 级经验 + 1 退魔砂。

## 实现要点（防回归注记）

- 锁状态在书的 `CUSTOM_DATA`：`cet_lock_mode`/`cet_lock_owner`（`TomeLock`，纯规则可测）。
- 取出拦截走容器层 mixin（`LockedTomeGuardMixin` → 书架 `removeItem/removeItemNoUpdate`），
  玩家手取与漏斗同一漏斗全堵；`UseBlockCallback` 只负责给被拒的玩家一句提示。
- 解锁标志就是成就本身（零新存档、天然持久化/同步）；判定与授予在既有的
  `computeLiveShelfState` 周期通道里完成（玩家感知重载，旧调用点签名不变）。
- 同步：`LiveShelfStatePayload` 增 `shelf_tomes`（上限 256）+ 两解锁旗 + 残卷计数；
  新服务端动作载荷 `TomeLockPayload`（上限 64 引用）与 `UnlockCleansePayload`；
  wire 升 **`26_3_revision_11`**，rev10 降为只查询探针（升级仍须两端同版）。
- 退魔门控在 `applyEnchantement` 的四种退魔 OptionType 入口服务端拦截，
  改客户端发包绕不过去。
- 定时锁对已满的书拒绝上锁并回提示；解锁扣费在背包内逐本结算（经验或退魔砂不足即停，
  已解锁的不回滚，反馈数量）。
