## 本轮处理

1. **术语**：清理简体中文中的“魔咒”等不自然附魔术语、重复词和冗长定价说明；动作使用附魔、升级、移除附魔等自然表达。固定材料名“退魔砂”保留，不随动作术语批量改名。11 个 locale 均为 984 keys。
2. **锁与等级**：锁定标记恢复为用户指定的 `🔒`，接受个别字体不显示的取舍。列表显示锁和下一等级，不再出现含义不明的 `II (22)`。书架需求转移至有完整名称的提示：当前、所需、还差多少；颜色继续表达状态。Unicode 检查只精确放行锁字符，不取消其余缺字/代理项检查。
3. **书架状态**：使用“普通书架”“书架总数”全称。普通书架的下一目标仅从已启用的直接升级、折扣（含最高折扣阈值）、顿悟门槛中选择；总书架数单独用于恢复，避免混用计数后给出错误差值。KEEP 或禁用恢复时不展示无效的恢复进度。
4. **顶栏**：移除厚重状态底板和进度条；标题、状态和右侧金色镶角留出独立区域。HUD 为 `(124,3,200,9)`；标题最大宽度 102。标签页位于 Y=-21、高18，底边在主面板上方3像素；配置/指南工具按钮同步移至 Y=-20。
5. **三个标签页**：附魔升级、移除附魔、典籍的六张 active/inactive 贴图统一为 150×36、金框和安静深色文字面板，保留紫/绿/青主题差异。去除妨碍文字的中央书图；文字 inset10、最大宽55。标签颜色只反映选择/解锁状态，不再依赖已移除的计数徽章。
6. **信息过载**：所有本模组 GUI tooltip 通过 `TooltipPresentation` 单一入口。默认摘要最多选5条原始信息，并在需要时提示 Shift；长文字先按字体换行，宽度不超过280且受视口限制，默认最多8行。红色风险信息优先于次要说明。Shift 展开技术细节，文字最多22行且受视口高度限制；大幅物品附图仅在主动展开时显示。原 tooltip 样式保留。书架默认仅当前数、下一差距和必要机制短说明；旧技术全文位于 `ResonanceDetailsTooltip`，仅 Shift 时构建并扫描对应上下文。

## 验收边界与跨分支反馈

- 自动几何断言不等于逐分辨率逐字体人工视觉验收；真实客户端最终成功结果和截图产物如上。Shift 展开仍有预算上限，不能宣称任意外部物品的全部附图/无限文本都能完整放进小视口。
- 用户已明确接受 `🔒` 的字体兼容取舍，不应在其它分支重新替换为空集状符号。
- 其它分支可移植纯 Java `TooltipBudget`、统一呈现策略、术语和贴图；`GuiGraphicsExtractor` tooltip 重载、`InputConstants` Shift 查询、SDL 输入与 `Screenshot` 渲染目标必须按各自 MC API 适配，不能照抄26.3签名。
- “下一目标”必须区分普通书架和总书架，也必须检查对应功能是否启用；禁止为了短文案重新合并两个计数。
