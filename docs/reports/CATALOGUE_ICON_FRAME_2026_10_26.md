# 目录图标按钮与内框约束 — 2026-10-26

源码：`3bd875ccfe0ce0b8001e404b33f193aa09953f9d`。保持 **1.1.0 / MC 26.3 / revision 11**；不改锁权限、费用或批量队列语义。

## 截图审查与修复

用户游戏截图暴露了上轮实现的问题：只给整个工具栏放了贴图，子控件仍用覆盖整个区域的平色矩形；没有依据贴图内框预留安全区域，hover/disabled 填充也容易盖住边框。点击、绘制、列表起点和 smoke 测试分别硬编码坐标，后续改尺寸时容易漂移。此前的业务/自动输入测试通过并不代表这类视觉问题已验收。

本轮不只替换图片：

1. **选择素材**：第一轮两张均被拒绝，按用户规则重新生成；第二轮第一张得到明确选择。采用其金色外框、紫色角饰和青色内圈，移除生成图外部画布后制作32×32像素游戏材质。不提交无关候选和大型生成图。
2. **共用材质**：`CatalogueSkin` 用同一套 normal/hover/disabled 材质绘制文本筛选控件、图标操作键和下拉菜单。九宫切片保留角饰，不把整张按钮背景横向拉伸。悬浮/禁用不再用覆盖边框的大矩形模拟。
3. **纯图操作键**：升降序、重置、全选可见、清空选择使用像素图标。右侧五个母版操作也改为同材质纯图标，横排置于原面板安全区内；名称、解锁费用、批量确认/风险说明保留在 tooltip。筛选当前值和选择数量继续用文字，避免纯图后看不懂当前条件。
4. **选择计数是读数**：不再兼任全选按钮；用独立全选图标，11 locale 的提示同步修正。
5. **内框约束**：外框留4 GUI像素安全边距；每个按钮的文字、图标再留3像素内边距。内容与外层都有 scissor，文本按可用宽高缩放/省略；图标只绘制在7像素以内的安全区域。高亮仅填在下拉选项内框，不覆盖菜单边框。
6. **布局单一来源**：纯 Java `TomeDirectoryLayout` 统一控件、下拉行、锁操作键、命中测试与列表偏移。`TableSkin` 的面板原点和尺寸也引用同一来源，避免“只移动面板、忘了移动操作键”。绘制/输入/真实客户端 smoke 均使用布局矩形，不再各写一份坐标。
7. **不以挤压换越框**：目录工具栏高59，列表从其下方留2像素间距后开始，原底边仍为主界面Y=158；为边框和图标留出空间，因此同屏书行略少。下拉最多显示5行并滚动，保证菜单也留在左目录内部、不盖住底边。无结果提示同步移到新列表区域。
8. 删除右侧不再使用的旧按钮资源常量，避免绘制层误接回旧样式。原六张顶部标签贴图不改。
